# 1 方向盘骨架与发泡本地开发方案

当前目标是把工程师在 CATIA 中手工完成的一段骨架或发泡工序，转成可重复执行、可以改参、能按 DS 检查的本地流程。方向盘正式 SOR 尚未指定。下列里程碑用于判断原型可行性，产品覆盖范围、设计限值和最终验收标准须由方向盘业务方确认。

当前先以手套箱把手底座验证“需求理解 → 参数配置 → 建模 → 检查 → 改参重试”的完整闭环，再迁移方向盘。这里的完整指自动化闭环，不代表已覆盖整件手套箱或全部 879 步。现场开发环境采用用户确认的 CATIA V5-6R2022；独立直线用例已通过，历史案例回放与 3DEXPERIENCE R2022x 兼容性仍待验证，不能互相替代。

## 1.1 从操作记录恢复设计意图

工程师按步骤建模，由 CA 导出 Python 和 JSON，并保留人工完成的模型。请工程师再做一份单参数变体，记录改了什么、为什么允许改、哪些几何应随之更新、哪些基准必须保持。两次操作配合讲解，才能区分设计输入、公式派生值、面边引用和结果测量值。CA 的导出完整性需在实际环境核对。

以发泡包络面偏置并封闭成实体为例，工程师指定支撑面、偏置侧和距离。将确认可调的距离连同单位、默认值及适用 DS 编号写入参数定义；封闭边界沿用上游几何引用，体积用于结果核对。若换面后引用指向另一面，即使体积接近也须判为引用异常。若工序需要人工选边，应把它列为显式输入或待解决步骤。方向盘流程第 28 页已将开口封闭的自动化列为疑问，可据此选择一个失败样件。

执行前检查必填参数、单位、范围和引用；建模后对实际几何独立测量。每条 DS 记录适用对象、规则版本、阈值来源、实测值与结果。没有业务方确认的限值时记录“待规范确认”。默认参数回放与原件比对；合法变体与人工变体及 DS 比对，避免旧模型的固定体积把正常设计变更判成错误。

手套箱首轮先抽取一个可变参数，通过后再增加第二个。优先选择工程含义明确、可测量且通常不改变特征数量的长度、偏置或角度；历史步骤 795 的拔模角度仅是候选，须先确认依赖与允许范围。每个输入记录原 JSON 字段、单位、默认值、范围来源、目标特征、受影响步骤和测量方法。原始导出包保留不变，变体使用单独配置；公式派生值、面边引用和历史测量基准不直接当作可调参数。

用户提供区间时，配置应分别表达允许范围、优选值及选择目标。只有范围而没有优化目标时，采用预先约定的取值策略并解释依据，不宣称最优；“加厚一些”等请求若无法映射到明确目标和单位，则先澄清。范围内搜索需要步长或候选集、最大尝试次数及停止条件。所有尝试均保留实际选值，不能只记录最终成功结果。

## 1.2 代码库应怎样支持迁移

实施时在代码库的 `cases/glovebox/` 纳入手套箱历史代码、运行所需的 JSON、引用数据和原生模板，保留原目录关系与可追溯的默认样例。把新方向盘流程和参数放在 `projects/steering_wheel/`。先通过最短可运行链路查明哪些操作能复用，再提取公共命令；方向盘的工艺顺序、特征定位策略和 DS 阈值留在方向盘项目内。

**glovebox 的交付包括代码和一份可供接手者独立运行的 README。** README 应随实际仓库更新，至少写清以下内容：

1. **脚本作用与依赖。** 列出入口和各手写脚本的职责、输入、输出、调用方及 CAD 副作用；批量生成的数据模块按同一机制分组。说明 `model_info.py` 提供模型信息，`sequence.py` 列出有序步骤，`_step_loader.py` 读取对应 JSON 并按特征类型查找处理函数，`_handlers.py` 实际调用 CAD。单列设计意图 CSV 的整理工具，避免误当运行入口。原包引用的上级模块如 `common`、`reconstruction` 和 `model_data` 须查明来源和版本，未补齐时注明具体阻塞点。
2. **一条真实调用流程。** 从实际启动命令写到连接 CATIA、装载模型和步骤、按依赖取得上游对象、调用处理函数、更新特征、测量和保存。用步骤 794–795 的凸台与拔模走读一次，指出终止面、角度分别来自哪里，哪一步重绑引用，哪一步比较输出。步骤清单本身不等于启动程序。给出经实机运行的环境、命令、样例输入、输出路径和预期日志。
3. **参数与检查。** 为选定案例列出原 JSON 字段、工程含义、单位、默认值、派生关系、几何引用及检查规则。提供默认回放、合法变参、违规输入各一个命令及预期结果，标明如何区分接口报错、引用失效和 DS 不合格。
4. **方向盘迁移对照。** 对每个拟复用命令列出在把手中的用途、依赖的 V5 接口、方向盘目标步骤、R2022x 实测状态及替代办法。例如先对照两边的曲面偏置，再检查输出是否保留参数、保存重开后能否编辑。未运行的接口标为待测。README 的验证方式是让另一位开发者按文档重放短链，并能指出迁移该操作需替换的输入与接口。

## 1.3 本地 Skill 如何驱动建模

Skill 将工程师意图转成已登记的流程名、目标特征和带单位参数。Python 执行器验证后调用限定的 CAD 操作，生成模型、测量记录和 DS 结果。命令行与 Skill 共用同一执行入口，便于判断偏差来自语义解析还是几何构建。遇到单位不明、目标面有歧义或参数越界，应返回可定位的问题。

识别到手套箱设计或修改意图时加载对应 Skill；一般咨询只解释，不直接建模。Skill 决定使用哪个已登记流程、选取哪些参数及如何根据失败结果调整策略。流程的阶段、参数绑定、检查点、检查项和允许的重试方式放入版本化 JSON/YAML 配置，避免全部顺序固化在单个 Python 脚本中。执行器校验配置的依赖与前置条件，负责 CATIA 会话、几何操作、恢复、测量和日志。模型不能跳过必需检查、改写 DS 阈值或任意重排有依赖的操作。首版仅实现本案例所需配置和执行接口，不提前开发通用工作流平台。

本地 API 模型本身不执行脚本，需要本地调度程序加载 Skill、提供工具接口、接收模型的结构化调用，再交给执行器运行，将测量与检查结果返回模型。一次执行应保留用户要求、解析后的配置、流程与脚本版本、模型调用和每次工具结果。模型提出的“成功”不能替代执行器的实际测量及规则判定。

模型权重、Qwen 推理服务、CAD 执行、输入输出及日志均部署在本地。通过 API 调用时，端点指向本机部署的服务，推理失败时报告错误，禁用公网回退。本地工作副本可使用 `.env.local` 存放端点及新签发的凭据，先将其加入 `.gitignore`；仓库提交仅包含无密钥的 `.env.example`。建库时用 `git check-ignore .env.local` 和 `git ls-files -- .env.local` 分别确认忽略规则生效、文件未被跟踪。已公开的旧凭据应在签发端吊销；日志与测试附件不得记录密钥。

## 1.4 检查失败后如何恢复与重跑

首版采用已保存的 CATPart 检查点恢复，先验证可靠性，再评估原地更新或删除特征的增量方式。下面的 91–97 是用户提出的流程示例，尚未映射或验证为历史包的实际操作：

```text
保存步骤 91 完成后的检查点
  → 参数 A 驱动步骤 92，执行 93–97
  → 检查失败，保存失败参数、测量和原因
  → 恢复步骤 91 的检查点及执行状态
  → 参数 B 驱动步骤 92，重新执行 93–97
  → 检查通过后继续后续阶段
```

修改配置后必须重新执行或更新步骤 92，不能只重跑 93–97。重跑集合按依赖关系计算；若其他已完成步骤也依赖 92，其结果必须失效并重新验证。检查点应绑定模型文件、流程版本、已完成步骤和对应参数。恢复后重新取得文档及特征引用，重建对象映射，不能沿用旧 COM 对象或只还原文件而保留旧执行状态。初版一个执行器串行拥有一个测试文档，恢复仅作用于该运行的测试件；人工未保存修改应使恢复停止。

失败分为输入不合法、CAD 更新失败、引用失效和工程检查不通过。只有已经定义调整策略且具备测量依据的失败才进入换参重试。环境错误或引用异常先定位原因；无可行候选、达到尝试上限或规范缺失时明确报告未完成。检查规则保持固定，缺少 DS 限值时可记录几何验证通过，但 DS 仍为待确认。

恢复能力的验收要比较“失败后恢复并改参重跑”与“相同参数从干净基线构建”的特征、引用和测量结果，并检查没有残留失败特征。已有直线测试的空白恢复仅验证整个测试件恢复，不证明中间检查点或历史链局部恢复已实现。

## 1.5 实施顺序与判据

| 顺序 | 实验 | 可复核的结果 |
|---|---|---|
| 1 | 以现场 V5 最小用例确认接口链路 | 已有创建、改参、保存重开和测量证据，详见实践跟踪；不外推为 R2022x 已通过 |
| 2 | 补齐 glovebox 上层模块和入口，固定参数回放含完整前置依赖的子流程 | 默认结果与基准对照，记录真实启动命令及引用；依赖无法取得时明确缩小实验范围，不宣称完整历史回放 |
| 3 | 单参数通过后扩展至双参数，由命令行驱动配置 | 默认值、合法变体、违规值分别验证；与人工变体及适用 DS 比对，写回 README |
| 4 | 引入中间检查点、失败恢复和有界换参重跑 | 至少一次真实检查失败后恢复成功；与同参从头构建对照；无解、引用异常和达到上限时按规则停止 |
| 5 | 接入手套箱 Skill、本地调度程序及本地 Qwen | 用户要求生成有效配置，模型通过工具执行；断外网可运行，命令行与 Skill 同参结果一致，保留全部尝试 |
| 6 | 按方向盘工程师录制和正式需求迁移 | 对照骨架或发泡人工原件及单参数变体；复核支撑、封闭、关联及项目 DS，不照搬手套箱限值 |
| 独立兼容验证 | 当明确要求部署 R2022x 时，在实际客户端验证接口 | 分别记录创建、改参、引用重绑、保存重开及测量结果，未测接口保持待测 |
