# 1 方向盘骨架实施步骤

本计划将签字版 SOR 的骨架范围拆成可开发、可检查、可恢复的阶段，尚未代表代码已经实现。用户需求及来源页码约定见 [[02_Projects/ai_cad/方向盘骨架与发泡用户需求]]，技术方案见 [[02_Projects/ai_cad/方向盘骨架与发泡本地开发方案]]。S 表示 SOR 物理页，F 表示设计流程 V1.1 页码，I 表示补充实施文档。发泡仅保留接口与准备任务，本篇不编造其操作步骤。

## 1.1 先准备可复核的输入与环境

1. 开发与IT维护当前环境和目标环境矩阵。当前使用本机V5-6R2022继续开发，复用已验证的执行器和方向盘通用操作；Python 3.12.9、V5 R24、客户V6等目标组合仍待对应环境实测。C04已确认驻场使用客户工作站V5-6R2024；新增R19后缀阶段件先在本机验证可打开性，失败后转现场核验。只有实际工序涉及未验证接口时才补充定向验证，不重新执行一套独立基础探针。
2. 业务提供 CAS、管柱、开关包络、时钟弹簧、底罩面、车身轴向、配置表、五系列平台库、Start Model、冻结范围及版本化 Checklist/DS。开发生成输入清单、哈希、单位、对象标识和装配变换。真实业务流程缺关键面或未知单位时停止并报告缺项；当前已收到四个阶段数模，先核对其内部输入及外部引用；合成演示保留作回归，不编造缺失业务尺寸。
3. 先解析step2–step5四个阶段CATPart，区分输入、构造几何及最终结果；工程师补充解释无法从特征历史确定的操作。原件只读；工作副本分别建立默认、单参数变体和失败样例。不能依据文件名中的“结果可见/全可见”认定几何相同，也不能把它们当作完整骨架基准。
4. 以阶段数模和知识表格提取设计意图、引用、可变量、单位、默认值来源和检查项目；缺少可解释操作时再请工程师补录PY/JSON。形成“流程页→录制步骤→特征→操作→检查”的映射表，再确定实际四位步号。开发先核对构造方法和形状关系，再实现对应操作；有意采用替代方法须说明差异及等效依据，不能因接口易用而静默替换。本篇阶段编号 B00–B90 是计划标识，不冒充录制步骤号。

每个阶段共用退出条件：CAD 更新成功、输出存在、引用可重绑、结果可保存重开；再执行工程检查。无 DS 阈值时为待规范，不能记通过。进入下一阶段前保存模型检查点和参数/输入/规则指纹；人工确认绑定这些指纹。

| B10 对称面与坐标系（S8；F4–8） | 从管柱圆柱面求轴线；四点配对连线及中点连线建立对称面；生成左侧 CAS 镜像检查；按C02指定的step2操作序列提取并实现原点构造；Y 为对称面法向、Z 为管柱方向，校准车身正向 | 检查轴线在面内及平行关系、左右偏差、轴向及右手正交性、投影唯一性；输出基准引用和对称性报告，等待用户确认。四点退化/多解停止；轴系改变使全部后续失效 |
| B20 辐板初始实体（S8；F9–11） | 按发泡/塑料底罩配置创建轮廓平面，与底罩面求交；圆轮廓按间隙偏置，非圆按C03指定的step3构造过程提取方案；闭合草图生成 Pad | 8.4mm 是资料默认厚度；发泡偏置3mm、塑料壁厚+1mm来自流程，须绑定配置及DS。检查闭合、间隙、厚度和无自交。回退到轮廓或Pad的最早改参步骤 |
| B25 辐板平台结构（S8；F25） | 依据管柱接口调用 HUB（锥面配合、12点对时）；时钟弹簧孔位及平台结构实例化；按结构和底罩配置优化辐板边界 | 检查孔位、方向、边界间隙及非对称特征。禁止整体镜像覆盖非对称辐板。输出辐板检查报告，待确认后冻结阶段基线 |
| B30 轮圈截面定位（S8–9；F12–16） | 校准6/9/12点方向；12点求闭合交线及中心，实例化标准截面；依据边界距离定位6/9点；根据分缝配置决定居中或下移 | 校核截面方向、中心、包覆余量、轮廓闭合；位置按流程保留1位小数时同时保存未舍入计算值。下移规则和截面尺寸未确认不得猜测 |
| B40 分段扫掠（F17） | 提取外圈引导线；区分三段连续与整段连续两种输入；按批准的比例截取6/9/12点引导线；建立三段扫掠，发布相应端部轮廓 | 检查扫掠方向、扭转、自交、端截面及CAS间隙。图中60%、30%、15%、20%必须逐分支确认，不能混成一套默认值。输出轮圈分段检查点 |
| B45 桥接及轮圈完成（S9；F18） | 配对12↔9、6↔9端部；依据F18及工程师操作记录确认桥接方法，再组合并按批准范围镜像。现有Loft能力是候选实现，不据此预设业务方法优先级 | 检查端点配对、连续性、闭合、连通、与CAS最小间隙；报告后用户确认。桥接失败可回到截面/引导线参数，不以扩大容差掩盖缺口 |
| B50 辐条配置和定位体（S9；F19–23） | 按开关、拨片、底罩间隙决定3/9点单/双辐条，配置决定6点辐条；创建与辐板重叠的定位体①；按A面中心创建②；在9点轮圈截面及引导线上创建③；按环境包络挖槽 | 流程20/30mm、45°、25mm、上下延伸4mm及4.2mm半厚均为待参数化基准。检查对手件间隙和截面厚度，不能把辐板8.4改参后仍固定半厚4.2 |
| B60 辐条连接与骨架组合（S9；F24） | 构建连接样条、填充面、合并封闭为④⑤连接体；合并到辐板和轮圈；按对称规则生成另一侧，保留非对称平台特征 | 检查曲面边界连续、封闭及实体连通、CAS和周边间隙；确认后继续。失败回到受影响定位体或样条，不重建无关轮圈分支 |
| B70 固定结构与全骨架检查（S9；F25） | 调用底罩、装饰件、线束等固定结构，生成定位坐标系及约束；检查所有适用DS和冻结区域 | 输出完整骨架、逐项检查报告、红绿标记、截图和偏差。缺库件/阈值阻止最终发布；体积对照不能替代检查 |
| B80 CAE加料与光顺（S10） | 输入独立CAE加料及环境数据，按辐板/轮圈/辐条分区进行加料光顺；检查覆盖CAE输入、制造可行性、光顺及DS | 这是CAD侧消费CAE结果，不擅自承诺仿真求解器。缺CAE输入可输出明确未完成的阶段件，不能标作可发布骨架 |
| B90 保存、复验与交付（S6、12、20） | 保存重开，修改一个已批准参数并重算；检查全参树、命名、发布引用；隐藏辅助几何并聚焦成品；生成最终工程文件和报告 | 对照人工基准及变体，核对未变区域、失败重跑与干净构建一致。给出可视验收截图与报告路径；所有未通过项明确展示 |

B50/B60先明确设计轴系、内外方向、边界引用和定位体关系，再建立样条及填充面。当前最简演示按用户补充同时检查两种形状：俯视下边界由外向内曲线收窄；沿辐条长度方向的Z高度先升后降，形成一次隆起并回落。用保存重开后的原生边界采样核对宽度与高度变化，并提供俯视、侧视或斜视供肉眼确认；截图视角不能代替设计轴系。端点、切向及准确尺寸待真实Part确定，不能从参考截图估算业务值。

同时检查特征树保留样条、Fill、Join、CloseSurface及下游组合/减料/镜像。平直回归样例仍可检查执行器，但不能作为上述造型出口；合成演示绕过的定位体①②③、环境选择和业务规则仍记缺项。体积、间隙和导出实体数量各自证明限定性质，不能替代曲面形状、连续性或完整DS检查。

## 1.3 首个可变量及恢复实验

B10→B20的辐板厚度是基础开发链，已有本机通用能力不重复开发；真实业务样件到位后，再用资料默认8.4mm及工程师批准的变体补充业务对照。B30→B45继续补齐实际截面定位/下移规则。范围/目标驱动的自动搜索尚待实现，参数范围、分缝映射和检查限值有明确依据后再接入。

每个单参数 JSON 约定：步骤ID、目标逻辑特征ID、操作、一个设计参数的名称/值/单位/来源/允许范围、上游对象、派生公式及适用检查ID。规则文件单独版本化，模型不得改检查限值。示例命名 `step_0020_Pad_辐板厚度.json` 仅为约定示例，实际序号以录制映射为准。

业务复现实验：在批准范围内构造一个违反间隙检查的轮圈参数；执行到检查失败，保存实测值及最小距离所在面；模型只提出新的一个参数值。执行器根据绑定定位到B30的具体截面步骤，重跑其受影响下游，作废旧轮圈/辐条确认；辐板未受影响时保留。新工序首次接入恢复链时，用同参数干净构建对照几何、引用、检查结果和未变分支。直接复用已有分支保留机制，不再将其列为从零开发前置任务。合成失败用例与真实业务检查分别记录，检查限值在同一运行中保持不变。

已有执行器支持跨进程状态、缺输入、工程不合格、技术故障及绑定指纹的确认，后续工序复用并验证自身依赖，详见代码仓 `D:\ai_cad\projects\steering_wheel\STATUS.md`。这不表示业务确认策略已经确定：C01已要求保留人工确认节点，不得默认自动放行，最多三次重试包含哪些异常仍待确认，不能通过新运行编号或恢复检查点重置预算。

各阶段维护独立脚本、参数样例、验证BAT、README及适用Skill，先CLI验证再宿主集成；这不要求每次修改都重新打包。Skill负责识别意图、解释参数/检查、处理决策和等待确认；不可重写工程操作和DS。工具返回稳定对象ID、版本、测量、错误类别与报告路径，沿用现有接口，仅随实际业务需要补充，不重建Agent。

每次开发选择一个明确业务缺项，先确认对应流程、输入及形状要求，再实现并完成相关验证、保存Git进度。恢复机制变化或新工序接入时做必要恢复对照；依赖/安装结构变化及正式发布时做新目录安装验证。其余时候不扩展孤立探针、不重复全量测试或打包；P5的正式测试与至少三轮调优仍按用户需求执行。
