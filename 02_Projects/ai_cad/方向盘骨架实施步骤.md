# 1 方向盘骨架实施步骤

本计划将签字版 SOR 的骨架范围拆成可开发、可检查、可恢复的阶段，尚未代表代码已经实现。用户需求及来源页码约定见 [[02_Projects/ai_cad/方向盘骨架与发泡用户需求]]，技术方案见 [[02_Projects/ai_cad/方向盘骨架与发泡本地开发方案]]。S 表示 SOR 物理页，F 表示设计流程 V1.1 页码，I 表示补充实施文档。发泡仅保留接口与准备任务，本篇不编造其操作步骤。

## 1.1 先准备可复核的输入与环境

1. 开发与 IT 核对 Python 3.12.9、V5 R24 及客户 V6 的实际版本和许可证；先在目标环境验证连接、创建特征、单参数更新、保存重开、测量、恢复，再复用已有执行器。输出环境矩阵和接口探针记录。V5-6R2022 手套箱通过记录只能作参考。
2. 业务提供 CAS、管柱、开关包络、时钟弹簧、底罩面、车身轴向、配置表、五系列平台库、Start Model、冻结范围及版本化 Checklist/DS。开发生成输入清单、哈希、单位、对象标识和装配变换。缺关键面或未知单位在建模前停止，输出对象级缺项报告。
3. CAD 工程师用两个参考 CATPart 讲解轮圈阶段，确认哪些是输入、构造几何和最终结果。原件只读；工作副本分别建立默认、单参数变体和失败样例。不能依据文件名中的“结果可见/全可见”认定几何相同，也不能把它们当作完整骨架基准。
4. 工程师从输入基线手动复建并录制 PY/JSON，每步补充设计意图、引用、可变量、单位、默认值来源和检查项目。形成“流程页→录制步骤→特征→操作→检查”的映射表，再确定实际四位步号。本篇阶段编号 B00–B90 是计划标识，不冒充录制步骤号。

每个阶段共用退出条件：CAD 更新成功、输出存在、引用可重绑、结果可保存重开；再执行工程检查。无 DS 阈值时为待规范，不能记通过。进入下一阶段前保存模型检查点和参数/输入/规则指纹；人工确认绑定这些指纹。

## 1.2 按阶段实现骨架

| 阶段与来源 | 输入与操作细化 | 检查、产物与回退 |
|---|---|---|
| B00 数据加载、选型与 CAS 校核（S6–7） | 校准输入坐标；按 CAS 尺寸和配置从平台库选择布局并装配；识别冻结对象；计算 CAS 与布局最小间隙 | 输出选型依据、候选及 CAS 报告。选型不唯一交业务决策；输入变化回到加载/选型，未受影响对象保留 |
| B10 对称面与坐标系（S8；F4–8） | 从管柱圆柱面求轴线；四点配对连线及中点连线建立对称面；生成左侧 CAS 镜像检查；按确认的原点规则投影到底罩面；Y 为对称面法向、Z 为管柱方向，校准车身正向 | 检查轴线在面内及平行关系、左右偏差、轴向及右手正交性、投影唯一性；输出基准引用和对称性报告，等待用户确认。四点退化/多解停止；轴系改变使全部后续失效 |
| B20 辐板初始实体（S8；F9–11） | 按发泡/塑料底罩配置创建轮廓平面，与底罩面求交；圆轮廓按间隙偏置，非圆采用确认后的拟合方案；闭合草图生成 Pad | 8.4mm 是资料默认厚度；发泡偏置3mm、塑料壁厚+1mm来自流程，须绑定配置及DS。检查闭合、间隙、厚度和无自交。回退到轮廓或Pad的最早改参步骤 |
| B25 辐板平台结构（S8；F25） | 依据管柱接口调用 HUB（锥面配合、12点对时）；时钟弹簧孔位及平台结构实例化；按结构和底罩配置优化辐板边界 | 检查孔位、方向、边界间隙及非对称特征。禁止整体镜像覆盖非对称辐板。输出辐板检查报告，待确认后冻结阶段基线 |
| B30 轮圈截面定位（S8–9；F12–16） | 校准6/9/12点方向；12点求闭合交线及中心，实例化标准截面；依据边界距离定位6/9点；根据分缝配置决定居中或下移 | 校核截面方向、中心、包覆余量、轮廓闭合；位置按流程保留1位小数时同时保存未舍入计算值。下移规则和截面尺寸未确认不得猜测 |
| B40 分段扫掠（F17） | 提取外圈引导线；区分三段连续与整段连续两种输入；按批准的比例截取6/9/12点引导线；建立三段扫掠，发布相应端部轮廓 | 检查扫掠方向、扭转、自交、端截面及CAS间隙。图中60%、30%、15%、20%必须逐分支确认，不能混成一套默认值。输出轮圈分段检查点 |
| B45 桥接及轮圈完成（S9；F18） | 配对12↔9、6↔9端部；先验证多截面实体，若使用曲面路线则填充/缝合/封闭；组合并按批准范围镜像 | 检查端点配对、连续性、闭合、连通、与CAS最小间隙；报告后用户确认。桥接失败可回到截面/引导线参数，不以扩大容差掩盖缺口 |
| B50 辐条配置和定位体（S9；F19–23） | 按开关、拨片、底罩间隙决定3/9点单/双辐条，配置决定6点辐条；创建与辐板重叠的定位体①；按A面中心创建②；在9点轮圈截面及引导线上创建③；按环境包络挖槽 | 流程20/30mm、45°、25mm、上下延伸4mm及4.2mm半厚均为待参数化基准。检查对手件间隙和截面厚度，不能把辐板8.4改参后仍固定半厚4.2 |
| B60 辐条连接与骨架组合（S9；F24） | 构建连接样条、填充面、合并封闭为④⑤连接体；合并到辐板和轮圈；按对称规则生成另一侧，保留非对称平台特征 | 检查曲面边界连续、封闭及实体连通、CAS和周边间隙；确认后继续。失败回到受影响定位体或样条，不重建无关轮圈分支 |
| B70 固定结构与全骨架检查（S9；F25） | 调用底罩、装饰件、线束等固定结构，生成定位坐标系及约束；检查所有适用DS和冻结区域 | 输出完整骨架、逐项检查报告、红绿标记、截图和偏差。缺库件/阈值阻止最终发布；体积对照不能替代检查 |
| B80 CAE加料与光顺（S10） | 输入独立CAE加料及环境数据，按辐板/轮圈/辐条分区进行加料光顺；检查覆盖CAE输入、制造可行性、光顺及DS | 这是CAD侧消费CAE结果，不擅自承诺仿真求解器。缺CAE输入可输出明确未完成的阶段件，不能标作可发布骨架 |
| B90 保存、复验与交付（S6、12、20） | 保存重开，修改一个已批准参数并重算；检查全参树、命名、发布引用；隐藏辅助几何并聚焦成品；生成最终工程文件和报告 | 对照人工基准及变体，核对未变区域、失败重跑与干净构建一致。给出可视验收截图与报告路径；所有未通过项明确展示 |

## 1.3 首个可变量及恢复实验

第一条垂直链优先完成 B10→B20 的辐板厚度，不直接从复杂轮圈桥接开始。默认8.4mm与工程师批准的另一厚度分别独立构建，核对厚度、体积变化、支撑位置、引用和保存重开。第二条链再实现 B30→B45 的轮圈截面定位/下移；参数范围、分缝映射和检查限值由业务批准后才启用搜索。

每个单参数 JSON 约定：步骤ID、目标逻辑特征ID、操作、一个设计参数的名称/值/单位/来源/允许范围、上游对象、派生公式及适用检查ID。规则文件单独版本化，模型不得改检查限值。示例命名 `step_0020_Pad_辐板厚度.json` 仅为约定示例，实际序号以录制映射为准。

复现实验：在批准范围内构造一个违反间隙检查的轮圈参数；执行到轮圈检查失败，保存实测值及最小距离所在面；模型只提出新的一个参数值。执行器根据绑定定位到 B30 的具体截面步骤，恢复其前置状态，重跑 B30/B40/B45 及已依赖该轮圈的辐条，作废旧轮圈/辐条确认；辐板未受影响时应保留。用新参数从干净基线独立构建，对比几何差异、引用、DS结果和未变分支。此实验要先补齐分支保留机制，不能把手套箱整件快照的后缀重建当作局部更新验收。

执行器必须持久化 `waiting_confirmation`、`needs_input`、工程不合格和技术故障等独立状态；确认接口及报告指纹校验是待开发能力。无人值守自动放行仅在业务签认后启用。最多三次重试的计数包含哪些异常需确认，不能通过新运行编号或恢复检查点重置预算。

## 1.4 开发顺序、责任与阶段出口

| 顺序 | 主责及工作 | 完成证据 |
|---|---|---|
| P0 | 业务/CAD/IT确认输入、DS、配置歧义、环境及交付责任 | 签认表、样件身份、环境矩阵，关键缺项有负责人 |
| P1 | CAD工程师录制默认及单参变体；开发补齐基础操作 | B10/B20独立PY+JSON+BAT通过目标环境实测 |
| P2 | 开发实现平台结构、轮圈与桥接；业务确认定位规则 | B25–B45阶段件及检查报告；一次真实失败恢复对照 |
| P3 | 开发实现辐条、固定结构和CAE数据处理 | B50–B90骨架全链；非对称结构及冻结区不被错误镜像 |
| P4 | 开发完善依赖、单参更新、确认、报告及Skill；IT联调宿主 | 不逐步调用模型；跨进程恢复、过期确认拒绝、局部更新证据 |
| P5 | 测试/业务/IT在客户环境进行至少三轮调优 | 基线/泛化分组测试、工作站/VDI与V6兼容结果、性能及发布清单 |

每个阶段交付独立脚本、参数样例、验证BAT、README及适用Skill，先CLI验证再宿主集成。Skill负责识别意图、解释参数/检查、处理决策和等待确认；不可重写工程操作和DS。工具需返回稳定对象ID、版本、测量、错误类别与报告路径。接口名称沿用现有自动执行思想，具体方向盘协议在P1冻结，不把本篇示例当成已存在命令。

## 1.6 测试集合与发泡衔接

骨架至少覆盖圆/非圆辐板、发泡/塑料底罩、单/双辐条及6点辐条开关、两种引导线分段、不同分缝、非对称平台特征、替换CAS、缺面/重名/断引用、非法参数、检查失败、回退耗尽、人工修改和冻结数据。基线生成成功率与跨项目泛化成功率分别统计，样本不能由同一个零件的显隐版本充数。项目验收要求见用户需求 R21–R24，未测试不得写成通过。

发泡移交包应包含骨架最终版本、基准轴系、关键发布引用、CAE状态、冻结区和DS报告。发泡操作补录后另开实施文档，验证其对骨架变更的依赖及厚度/间隙检查；不把骨架示例参数直接用作发泡工艺值。
