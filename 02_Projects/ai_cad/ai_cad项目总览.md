# 1 ai_cad 项目总览

代码仓与逐步验证结果见 [[02_Projects/ai_cad/参数化建模实践跟踪]]。

当前改造目标：交付独立执行脚本、Skill 及必要资产，由预定义 Pipeline 自动推进，模型只在需要决策时介入；改参后执行器计算回退位置并重跑。Qwen 驱动仅作开发验收。当前交付边界及验收见开发方案 §1.8，该节替代 §1.7 的逐阶段模型编排目标；历史通过记录不等于本次改造已完成。

2026-11-14 本次改造已在限定手套箱子流程验收：22 次独立 CLI 命令、失败后自动回退、同参构建对照及交付包新目录实测通过；Qwen 只查询流程、启动和提交参数变化。当前证据见实践跟踪 §1.10，交付位于 `D:\ai_cad\delivery\glovebox`。正式本地推理、方向盘需求和 DS 尚未验收。

当前项目为方向盘骨架与发泡，要求纯本地部署，正式 SOR 待指定。[[02_Projects/ai_cad/方向盘骨架与发泡本地开发方案]] 说明如何从工程师操作记录提取可变参数、按 DS 校验，并用本地 Skill 驱动 CATIA。

2026-11-14 更新实施顺序：先在现场 CATIA V5 中用手套箱把手底座验证默认回放、一至两个可变量、检查点恢复和 Skill 闭环，再迁移方向盘。已验证的独立直线用例与尚待实施的历史回放、局部重跑、本地模型调用分开记录；R2022x 兼容性仍待独立验证。

同日完成圆形草图 701 → 凸台 794 的限定子流程、回归失败后的检查点恢复及公网 Qwen 工具调用，见实践跟踪 §1.7。定位及外部约束仍有冻结边界，完整历史回放与正式本地推理未完成。公网调用仅为用户授权的开发例外。

本轮验收已由用户明确为 Qwen API 闭环，本地部署留到正式阶段。修复 README/Skill 中文编码后，Skill 已改为建模、判读与失败恢复的执行流程，并通过两次动态工具调用实测，见实践跟踪 §1.9。正式本地推理和 DS 验收仍不在已通过范围内。
