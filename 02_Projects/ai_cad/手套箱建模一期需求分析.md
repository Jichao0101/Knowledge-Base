# 1 手套箱建模一期需求分析

一期要交付一个在 CATIA V6/3DEXPERIENCE 中运行的手套箱建模插件。客户提交未修整的 CAS A 面、周边件、设计要求及可用的参考断面或局部结构；系统据此识别输入、按规则动态求解断面和数模、自动装配、校验、纠错并出具报告。交付对象是含框的手套箱总成，覆盖侧翻、按压、电控三类，保留延锋规定的树结构、命名、完整参数关联和 KBE 日志。知识推理驱动的自主断面设计和多方案决策属于二期。

需求依据为 SOR 第 3.1 节、通用技术要求及第 4–8 章，指标和交付边界见 [[02_Projects/ai_cad/手套箱建模SOR关键要素]]。下文的 R2022x 是开发验证环境；SOR 指定 V6/3DEXPERIENCE，客户最终验收的补丁和许可配置仍待确认。本文给出需求分解与测试设计，实机结果待记录。

## 1.1 从输入到可交付总成，哪些工作需要新开发

历史把手提供“已知步骤怎样生成并核对特征”的经验；方向盘提供“工程师怎样选择支撑、参数与建模顺序”的案例。前者见 [[02_Projects/ai_cad/AI_CAD历史实现/历史实现说明]]，后者见 [[02_Projects/ai_cad/steering_wheel技术参考/方向盘技术参考说明]]。应用到手套箱时，应先说清每一步由谁提供输入，尤其要找出原案例里由人工完成的决定。

| 一期需求（SOR §3.1、§4、§5） | 可借鉴的方法 | 需要新开发的能力与可观察结果 |
|---|---|---|
| 导入并理解设计输入 | 方向盘流程为每项操作定义输入、输出和基准；把手案例区分功能体与配合件 | 识别 A 面、周边件、断面、硬点、左右舵和冻结范围；统一单位及装配坐标，保留来源。输入不合规时，指出文件与错误类型 |
| 修复 A 面并识别特征 | 缺陷图可选失败样例；方向盘按已知边界桥接、合并；把手用几何测量复核结果 | 自动定位缝隙、褶皱与连续性问题；选择局部修复策略，验证可偏置、可延伸并输出缺陷报告。识别卡扣、筋位、止口、孔位，输出类别、支撑几何、尺寸及单位 |
| 求解断面并生成参数化零件 | 把手按支撑、终止面、出模方向成形；方向盘先建料厚再布置 B 面结构 | 把客户定义、设计规范、工艺选配及配合件转成位置和尺寸约束。生成门体、框、定位安装和加强结构，支持焊接、包覆、Stopper 等选配。输出有可修改设计参数的原生特征树 |
| 空间避让、运动与装配 | 可借鉴方向盘保留切削体、分段布尔及局部坐标系的做法 | 从周边件和配置间隙构造禁止空间；自动找转轴，定义全开闭行程，计算包络并进行动态干涉检查；放置各结构件并验证装配约束。分别保存静态穿透/间隙与发生碰撞的姿态 |
| 设计变更与恢复 | 历史脚本遇到面边引用失效时重新绑定并核对几何；方向盘区分全量生成和单特征变更 | 在界面修改壁厚、筋尺寸或替换 CAS 后按依赖更新；验证受影响的配合件和冻结区。布尔失败尝试局部偏移或分段；单次建模失败回滚后调整参数重试，最多 3 次，仍失败则生成分析报告 |
| 自动工程校验、纠错与出报告 | 把手代码的几何比对可用于回归；方向盘把 DS 检查单列为工具 | 建立可视化配置的规则库，逐条保存规则版本、对象、实测值、阈值和结论。自动着色，输出清单、通过率、不合格项截图、偏差和优化建议；纠错后重新测量，留下前后结果及日志 |

**用一处铰链座验证整条链。** 选取带安装硬点、对手件和邻近风道的一组甲方数据，先生成铰链座并检查孔中心相对硬点的三维偏差，再沿开闭行程查最小间隙。让测试件在中间角度发生干涉、在两个端点均无干涉，检验系统能否定位碰撞。随后更换局部 A 面，观察孔、框上配合结构、冻结区及报告如何变化。这个用例把“正确建出一个零件”“运动过程中合格”和“修改输入仍保持关联”变成三个独立可复核的判断。

## 1.2 如何把验收条款变成测试判据

| 验收主题 | SOR 给出的条件 | 验收准备与证据 |
|---|---|---|
| 识别与泛化 | 一期表要求关键几何特征识别准确率 ≥99%；技术指标和 ≥30 个不同车型/客户的全新项目盲测要求识别 100%，该盲测同时要求建模成功率 100% | 分别统计测试集、盲测集和各特征类别。与甲方约定检测匹配容差、错检漏检、参数提取误差；封存盲测项目，避免同一车型的派生样本进入训练集 |
| 鲁棒性及一次成功 | A 面缺陷面积 ≤5% 时自动标注且其余区域可正常建模；常见特征一次创建成功率 ≥90%；3–5 个新结构样本完成基础识别，补充训练后准确率 100% | 分开记录初次成功与重试后成功。常规跨项目免微调与新结构小样本适应分别建组；缺陷面积以甲方标注的分母计算 |
| 规则、空间及无人干预 | 规范条目匹配 100%；禁止空间布尔成功率 100%；输入完整合规时从导入到生成无需人工操作的步骤占比 100%；全流程还包括自动检查及报告 | 预置已知安全间隙与穿透量，记录切除体积、最小距离和任何拾点、对话框或人工修补。重试、最终失败和未运行检查均单列 |
| 参数化、几何与制造质量 | 受影响特征更新覆盖度 100%；硬点孔位偏差 <0.1 mm。检查 G0/G1、微小边、非流形、破损、全域壁厚、拔模及圆角。SOR 中 ≥1°、≥R0.5 mm 为示例 | 孔位测试纳入 0.1 mm 临界失败件；按材料、部位、工艺读取批准阈值。另向甲方取得《手套箱建模交付质量规范》、强度、法规及客户专用规则，确认实测或仿真依据 |
| 运行与安全 | 建模和检查速度至少为纯人工的 10 倍；单个模型至少 20 个并发建模；本地 CPU/GPU 推理、总显存 ≤384 GB，支持 AES-256 本地加密和本地日志审计 | 对同一输入和检查范围计时，分别记录端到端耗时、吞吐、峰值显存、CAD 会话及许可占用。断外网复测导入到出报告，核对权重本地加载、任务隔离和加密范围 |

完整 SOR 还要求跨结构、跨数据质量、跨概念/详细设计阶段适配，并使核心推理引擎与 CAD 解耦，以便后续迁移 NX、Creo。建议用同一份识别结果驱动规则计算，再由 R2022x 执行建模；保留业务参数和可审计的几何测量值，使 CAD 会话标识只在执行该次任务时使用。

## 1.3 R2022x 上优先实测哪些接口

下表列的是要验证的调用能力。历史 V5 的 `Documents.Open`、`PasteSpecial("CATPrtCont")`、`CreateReferenceFromBRepName`、`SPAWorkbench` 以及 SOR 举例的 `DraftAnalysis`、`Clash` 都是查找线索。每项测试先记录实际安装的 R2022x 更新级别、HotFix、原生角色、许可证、开发接口/方法及输入样件，区分“可在界面操作”“可编程调用”“可无人值守读回结果”。此前 HF7 安装中断的对话记录不能证明机器现状。

| 优先级与接口能力 | 最小实测 | 通过证据 / 失败后要定位的问题 |
|---|---|---|
| P0 原生产品、形状与持久化 | 导入 CATPart/STEP；建产品、零件和装配关系，保存并重开；编译加载一个与目标更新级别匹配的 CAA/C++ 插件 | 可找到正确实例、参数及关联并二次编辑。区分数据转换、角色权限、存储服务与 SDK/编译环境问题 |
| P0 曲面与实体工厂、拓扑引用、参数更新 | 对一张缺陷 A 面桥接/缝合、偏置、封闭加厚，做凸台、筋、拔模及布尔；替换 A 面并改厚度，保存重开 | 对照原面量测、特征树、孔位置及冻结区；计入失效引用和错误重绑。另用失败样件验证清除半成品后可重试 |
| P0 装配、测量与静态干涉 | 两零件分别制造已知间隙、接触和穿透，交换装配实例；读取孔中心坐标、最近距离、穿透结果及对应面 | 用人工基准核对数值、单位和全局坐标，确认返回的是正确实例。若只能显示色彩图，记录缺少的数值接口 |
| P0 机构、全行程包络与动态碰撞 | 建立铰链、行程限位，运行上述中间角度碰撞样例；用更细采样或连续求解结果对照 | 回读首次干涉姿态、关联零件、间隙或穿透值，并记录角度步长及漏检边界；静态端点只能作为对照组 |
| P0 原生分析与结果提取 | 对带负拔模、局部薄壁、小圆角、G1 断点及正常对照的样件，调用分析并读取逐区域结果 | 回读数值、位置和失败类别；对照已知几何，验证阈值两侧判定及可着色对象。缺少公开接口时分别评估 CAA 或独立几何算法并验证等价性 |
| P1 可视化、报告、并发与回滚 | 以脚本触发着色、截图及报告；两个任务输入不同厚度，同时令一个失败，之后扩至 20 任务 | 报告能追溯到本次零件、姿态及规则；失败任务不污染其他模型和日志。记录会话并发限制、许可和资源瓶颈，分别验证恢复及吞吐 |

## 1.4 数据、交付与开工前需统一的口径

一期训练交付要求 A 面缺陷标注 ≥5000 张、断面特征 ≥2000 组、周边件约束 ≥500 组。需交付可视化标注工具（点云/曲面选取、框选、标签及 JSON/COCO 导出），以及采样转换、增强、断面归一化和 7:2:1 划分脚本。SOR 列出 PointNet++ / DGCNN 训练脚本、YAML 配置、训练曲线、早停和检查点，并要求交付 .pt 权重、ONNX 导出、本地推理包、分类别指标和难例分析。两组参考材料可以提供初始案例与建模语义，训练规模和跨项目精度仍需独立数据证明。

工程交付还包括技术方案、含接口与时序的详细设计、带测试及构建说明的 CAA/C++ 源码、可部署插件、校验和报告模块、中英文手册与在线帮助、测试用例与报告。第一阶段要求三个月内、全程驻场，使用甲方真实数据并至少三轮实测调优。建议先用端到端样例验证 P0 接口，再铺开三种总成及结构变体，最后用独立项目盲测完成验收。

在锁定用例前，应与甲方分别确认以下事项：

1. **输入合同。** SOR 将完整建模历史和 StartModel 排除在输入范围外，但参数提取验收同时提到断面或 StartModel。需约定必需/可选输入、参考断面缺失时的规则来源，以及冻结范围的表示方式。
2. **判定依据。** 分别签认 ≥99% 与 100% 对应的数据集和分母，明确 G0/G1、壁厚、强度及动态间隙判据，以及三种手套箱的必测配置。正文列 HTML/PDF/Excel，交付表列 HTML/PDF，需确认最终格式。
3. **部署边界。** 确认现场 R2022x 客户端、服务端、SDK 和角色；明确“全部计算在本地工作站”是否允许内网平台/许可服务，以及“单个模型 20 并发”计量的是 AI 推理还是含 CAD 建模与校验的端到端任务。以书面定义选择测试拓扑和人工计时基准。
