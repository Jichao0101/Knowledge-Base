## 1.5 当前未闭合覆盖区

### 1.5.1 理论诊断

1. **架构边界**：encoder、decoder、encoder-decoder 与 decoder-only 的输入、attention 可见性和任务差异。
2. **Transformer block**：multi-head attention、位置编码、residual、normalization 与 FFN 各解决什么问题，以及具体顺序为何依架构而异。
3. **证据边界**：幻觉、unsupported claim、引用证据、拒答和不确定性表达之间的关系。

### 1.5.2 受控实践

1. 独立实现并测试 scaled dot-product attention；至少覆盖 shape、softmax 维度、causal mask 和参考实现对照。
2. 固定输入与随机种子，改变 temperature、top-p、最大输出长度和上下文，记录可观察变化并解释原因。
3. 构造有证据与无证据对照，验证回答、引用、拒答和不确定性行为。
4. 复核现有 TinyCausalLM 是否真正闭合 `文本 → token → embedding → causal attention → logits → decoding → 文本`；未覆盖部分应显式补齐或记录边界。
