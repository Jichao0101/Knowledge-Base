# 1 VLM 数据标注规范学习与试标方案

专题正文统一从[[02_Projects/AI-Career-Transition/10_学习文档/P02A-02_VLM数据标注_学习文档|VLM 数据标注指南]]进入。指南按九类任务组织填写与验收方法。下面的四份通用数据集拆解和两份驾驶领域对照是其中的精读样本；查阅任务类别时可直接使用指南开头的导航表。

已有框、mask 和类别标注经验后，下一步要弄清一幅图怎样成为一条可训练、可评分的多模态样本。学习从公开数据的生产过程开始。等能够解释不同标注方式的成本与证据要求，再决定自己的任务需要哪些字段、哪些可以自动派生、哪些值得人工采集。

## 1.1 1　拆解通用数据集

从[[04_Sources/模型工程/2026-11-07_VLM数据集标注方案来源对照]]进入原始资料。先比较 Visual Genome 和 VQA v2，观察人工描述局部事实与多人独立回答同一问题分别保留了什么信息。接着读 GQA，手工沿场景图求出一个答案。最后看 LLaVA 的一条生成样本，判断已有描述和对象框能支持回答到什么程度。

每份先选 3～5 条有差异的样本作精读，包含普通样本和暴露标注边界的样本。保留样本 ID 或原始链接。每份写一页，围绕同一条样本回答下面的问题。

| 拆解问题 | 一页笔记中要留下的内容 |
|---|---|
| 标注单位和可见信息是什么？ | 指明图像、区域、对象对、问题或视频片段，以及标注员能看到的上下文。 |
| 一条监督信号由谁产生？ | 顺着实际流程写出人工观察、规则派生、教师生成与复核分别出现在哪一步。 |
| 答案依据在哪里？ | 用样本指向具体区域、关系、时间段或人工回答。资料未披露的步骤标为“未披露”。 |
| 字段由谁使用？ | 区分模型输入、训练目标、数据生成所需信息和评测参考，特别标出推理时不可用的信息。 |
| 评分能识别哪种错误？ | 自拟一条边界答案，按公开规则复算或人工核对，解释同义表达、证据不足和事实错误会怎样影响评分。 |

## 1.2 2　比较驾驶领域，再选择自己的任务

用同一套问题精读 Drive&Act 的一段活动和 DriveLM-nuScenes 的一组关键帧问答。补记形成判断所需的最短观察范围，以及实际推理时能否取得相同信息。产出两份领域对照后，再从已有座舱任务中选择一个试标对象。工具调用与追问的标注方法见指南的工具使用和多轮交互章节。

## 1.3 3　在小批样本上检验规范

首轮可使用熟悉的整图双眼定位与四类状态任务。复用已有框和状态，选取清晰、遮挡及双眼关联容易混淆的样本，尝试生成整图结构化结果与指定眼睛的局部问答。对每一种表示，记录哪些内容可由已有标签确定、哪些需要重新观察，以及评分能否定位左右眼关联错误。根据比较结果选择首版监督方式。

将选择写成一份规范草案，涵盖标注单位、允许观察的输入、字段含义、正反例、不可判定条件、派生规则与评分方式。首次试标由两人独立处理同一小批样本，保留原始判断和分歧原因。若双方看到了不同的视觉事实，就补充观察条件或边界样例。若事实一致但选了不同标签，就修改字段定义或仲裁规则，再用另一批样本复验。

公开资料的学习产物是四份通用拆解和两份领域对照。自有规范的试标结果由后续实践记录保存，包括样本范围、规则版本、分歧实例和修订依据。

## 1.4 前两步的学习材料与迁移判断（2026-11-07）

从已有的框标注出发，先读[[04_Sources/模型工程/Visual Genome_从区域短句到对象关系]]，观察一句局部描述怎样关联对象及关系。接着读[[04_Sources/模型工程/VQA v2_从多人回答到评分]]，亲算“桌子”和“野餐桌”各得多少分。两篇放在一起可以看出，定位对象正确以后，回答者仍可能在空间参照和措辞上产生分歧。

接下来读[[04_Sources/模型工程/GQA_沿场景图求解组合问题]]，从米饭出发沿两条关系边找到餐巾，重算一道派生题。再读[[04_Sources/模型工程/LLaVA_从已有标注生成指令]]，核对公交车的五条原始描述与教师给出的单一回答。设计监督时，可以让程序从确定的字段生成问答；当来源本身有分歧时，生成更长的回答不会补上缺少的观察证据。

领域对照把这个问题落到时间上。[[04_Sources/模型工程/DriveAndAct_同一动作的三层时间标注]]用同一帧号区分任务、动作和手部交互。[[04_Sources/模型工程/DriveLM_同一关键帧的三种监督]]用同一关键帧区分视觉对象、运动判断与策略建议。结合两项对照，第三步建议仍选已有整图双眼定位与四类状态任务：先检查单帧可判断的属性、左右关联和遮挡，再讨论哪些问题确实需要连续帧。试标记录待实际执行后建立。
