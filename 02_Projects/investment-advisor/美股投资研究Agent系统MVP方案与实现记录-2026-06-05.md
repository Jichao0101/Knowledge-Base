# 1 美股投资研究 Agent 系统 MVP 方案与实现记录

## 1.1 目标

在空仓库 `/mnt/d/investment-advisor` 中搭建一个可运行、可测试、可扩展的个人美股投资研究 Agent 系统 MVP。

系统目标：

- 基于 OpenBB-style 数据层，MVP 阶段使用 mock market data provider。
- 基于 SEC/EDGAR 证据层，MVP 阶段使用本地 JSON mock filings。
- 基于 TradingAgents-style 多角色研究层，但不复刻 TradingAgents 原仓。
- 生成每日投资研究草案、昨日建议复盘、表现归因、反馈 memo 和 thesis memory 更新。
- 重点约束负反馈调节，避免把一天涨跌直接当作强化或否定研判逻辑的依据。

系统边界：

- 仅用于个人投资研究辅助。
- 不做自动下单。
- 不接入券商 API。
- 不承诺收益。
- 不输出正式投顾建议。
- 所有建议必须标记为 `research draft / 投资研究草案`。

## 1.2 架构方案

当前 MVP 分层如下：

| 层               | 当前实现                                     | 后续替换方向                                                  |
| --------------- | ---------------------------------------- | ------------------------------------------------------- |
| Market Data     | `MockMarketDataProvider` 读取本地 JSON       | OpenBB quote/fundamental/valuation/sector/macro adapter |
| SEC Evidence    | `MockSecEvidenceStore` 读取本地 JSON filings | SEC Search / EDGAR adapter                              |
| Research Agents | deterministic mock votes                 | LLM provider + 多角色 agent adapter                        |
| Attribution     | `AttributionEngine`                      | 加入更长窗口、更细行业/风格因子                                        |
| Feedback        | `FeedbackController`                     | 加入长期 calibration、rolling attribution、policy persistence |
| Thesis Memory   | 进程内 `ThesisMemory`                       | 文件/数据库持久化                                               |
| Report          | markdown + JSON output                   | audit id、版本化报告、证据链接校验                                   |

## 1.3 关键 schema

核心 schema 位于 `/mnt/d/investment-advisor/investment_agents/schemas.py`：

- `MarketSnapshot`
- `SecEvidence`
- `AgentVote`
- `Thesis`
- `RiskFactor`
- `InvestmentReport`
- `PerformanceFeedback`
- `PolicyState`
- `FeedbackMemo`

MVP 使用 Python `dataclasses`，避免空仓库初期引入安装依赖。后续若需要更强校验和 JSON schema 导出，可迁移到 Pydantic。

## 1.4 负反馈调节机制

负反馈机制拆为两步：

1. `AttributionEngine` 解释发生了什么。
2. `FeedbackController` 只输出研究流程调整 proposal。

Attribution 至少计算：

- `raw_return`
- `market_adjusted_return`
- `sector_adjusted_return`
- `residual_return = ticker_return - sector_return`
- `direction_score`
- `calibration_score`
- `risk_score`
- `evidence_score`

Feedback 输出只允许包括：

- `prompt_focus`
- `confidence_calibration`
- `agent_weight_proposal`
- `risk_penalty_proposal`
- `thesis_status_updates`

禁止输出：

- 买入/卖出指令
- 自动仓位调整
- broker/order API 调用
- “确定收益”或正式投顾式建议

## 1.5 Review 后修正的关键点

subpower reviewer 发现并推动修复了两个高风险问题：

1. **Thesis 不能因单日反馈直接 confirmed/invalidated**
   - 修复后：单日 feedback 可以让 thesis `weakened` 进入复查。
   - `confirmed` 或 `invalidated` 需要样本充足，并且 invalidation 还需要 thesis-specific signal。

2. **Agent weight proposal 不能按整体方向一刀切**
   - 修复后：按每个 agent 的 stance direction 与 residual-return direction 对比。
   - 只有方向性 agent 且个体方向对/错明确时，才提出权重调整。
   - 单日最大调整不超过 5%。
   - 单 agent 权重范围保持 10% 到 45%。

同时修正：

- markdown report 增加 attribution audit inputs。
- agent votes 增加 evidence refs 输出。
- `risk_score` 表示风险检查覆盖度，不再把“风险严重”误当作“风险检查差”。

## 1.8 测试覆盖

当前测试覆盖：

- schema 可实例化。
- `residual_return = ticker_return - sector_return`。
- 高置信度方向错误触发 calibration 下调。
- low evidence score 触发补充 SEC/EDGAR evidence 的 prompt focus。
- low risk coverage score 触发 risk review prompt focus。
- 单日 feedback 可以 weaken thesis，但不能直接 invalidate。
- thesis invalidation 需要样本充足和 thesis-specific signal。
- raw return alone 不改变 calibration、agent weights 或 thesis status。
- mixed agent votes 只调整方向明确且个体判断对/错的 agent。
- agent weight proposal 满足 5%、10%-45% 约束。
- report markdown 包含必需章节、audit inputs 和 evidence refs。

## 1.10 后续扩展建议

1. 增加 OpenBB adapter contract tests。
2. 增加 SEC/EDGAR adapter，保留 accession number、filing type、filing date 和 source URL。
3. 增加 LLM provider adapter，要求输出结构化 `AgentVote`。
4. 增加 rolling attribution window，避免短期样本过拟合。
5. 将 thesis memory 和 policy state 持久化。
6. 给 report 增加 audit id、输入快照哈希和证据链接校验。
7. 把 feedback policy 变更做成人工确认流程，而非自动应用。

## 1.11 风险与边界

- 当前 MVP 的 mock data 不代表真实市场数据。
- 当前 agent votes 不代表真实 LLM 研究质量。
- 当前 attribution 只覆盖最小基准，不覆盖风格因子、宏观冲击或事件驱动噪声。
- 当前 thesis memory 未持久化。
- 当前 report 是 research draft，不是投资建议。
