# 1 项目总览

本文件是 `02_Projects` 的项目区入口。项目当前事实以对应项目总览、模块 `overview_current` 或项目记录为准。

## 1.1 项目入口

| 项目 | 入口 | 当前结构状态 |
|---|---|---|
| DMS | [[02_Projects/DMS/DMS项目总览]] | 已补项目级入口；多个模块已有 current 文档组 |
| cutepower | [[02_Projects/cutepower/cutepower_overview_current]] | 有 overview/design/spec/interface/implementation/validation current |
| subpower | [[02_Projects/subpower/subpower_architecture_blueprint_current]] | 有 architecture current 和 implementation records |
| codex capability registry | [[02_Projects/codex-capability-registry/Codex plugin skill 集中注册与迁移方案]] | 单主题项目记录 |

## 1.2 项目区读取规则

1. 优先进入项目入口，不从历史记录或运行工件开始读。
2. 若项目存在 current 文档组，优先读取 `overview_current`。
3. 若项目没有 current 文档组，只读取任务直接相关的设计、实验或实现记录。
4. `subpower_runs`、`Current Maintenance Records`、baseline 和历史方案只作为证据补充或追溯材料。

## 1.3 结构风险

- DMS 内部模块的 current 成熟度不一致。
- 部分项目记录仍是单文件或历史记录形态，不具备默认恢复入口。
- 后续新增项目应先在本文件登记入口，避免项目区继续出现孤立文件。
