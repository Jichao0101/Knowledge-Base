
# 1 综述
## 1.1 统一约定

### 1.1.1 输入样本

每个输入样本为：

- `(ts_k, b_k, count_enable_k, cancel_alarm_k)`

其中：

- `ts_k`：时间戳，单位 `ms`
- `b_k = 1`：当前行为为正
- `b_k = 0`：当前行为为负
- `count_enable_k = 1`：允许计时
- `count_enable_k = 0`：工况无效
- `cancel_alarm_k = 1`：用户点击取消报警

若无特殊说明：

- `count_enable_k = 1`
- `cancel_alarm_k = 0`

### 1.1.2 采样步长

- `Δt = 50 ms`

### 1.1.3 输入构造记号

仅使用连续片段：

- `[t1, t2] = 1`
- `[t1, t2] = 0`
- `cancel_alarm(t) = 1`
- `count_enable([t1, t2]) = 0`

### 1.1.4 细化覆盖要求

除无冷却期的重度疲劳外，其余每类报警均给出 **19 个 case**，固定覆盖：

1. 触发阈值，无翻转：略小于 / 等于 / 略大于
2. 触发阈值，低翻转稀疏分布：略小于 / 等于 / 略大于
3. 触发阈值，低翻转集中分布：略小于 / 等于 / 略大于
4. 退出阈值，无翻转：略小于 / 等于 / 略大于
5. 退出确认被打断：稀疏 / 集中 / 打断后再次达到阈值
6. 用户取消
7. 冷却期：略小于 / 等于 / 略大于

### 1.1.5 阈值偏移规则

对所有阈值均采用：

- 略小于阈值：`T - 50 ms`
- 等于阈值：`T`
- 略大于阈值：`T + 50 ms`

### 1.1.6 桥接长度规则

测试桥接上限统一取：

```text
G_max = T_off - 50 ms
```

其中：

- 轻度疲劳：`G_max = 150 ms`
- 长时分心：`G_max = 200 ms`
- 累积分心：`G_max = 200 ms`  
  说明：累积分心与长时分心使用同一桥接长度，不使用 `2000 ms`
- 头部姿态异常：`G_max = 200 ms`
- 抽烟：`G_max = 450 ms`
- 电话：`G_max = 450 ms`
- 重度疲劳：`G_max = 350 ms`

### 1.1.7 冷却期一致性

按规范：

- 满足退出条件退出报警
- 用户点击取消报警退出报警

上述两种情况，均进入同一冷却期，处理无区别。
