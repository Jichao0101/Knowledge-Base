
## 0.1 疲劳驾驶监测报警条件

### 0.1.1 触发疲劳报警等级条件

| 等级 | 判断条件 |
|---|---|
| 轻度疲劳 | 1. 单次闭眼持续 2~3 秒（2s ≤ t < 3s）；或 |
|  | 2. 若开启哈欠检测，即 `FATIGUE_YAWN_DETECT = 1`，出现 1 次持续 3 秒以上的哈欠（t ≥ 3s） |
|  | 说明：以下嘴唇中心关键点的距离超过阈值开始统计 |
|  | 配置信息（闭眼）：`FATIGUE_TIME_LOW = 2`，`FATIGUE_TIME_HIGH = 3` |
|  | 配置信息（哈欠）：`FATIGUE_YAWN_DETECT = 1`，`FATIGUE_YAWN_TIME = 3` |
| 重度疲劳 | 单次闭眼持续超过 3 秒（t ≥ 3s） |
|  | 配置信息（闭眼）：`FATIGUE_TIME_HIGH = 3` |

### 0.1.2 退出疲劳报警等级条件

| 等级 | 判断条件 |
|---|---|
| 轻度疲劳 | 1. 非闭眼时长超过 0.2 秒（t ≥ 0.2s）；或 |
|  | 2. 用户 Dismiss Alert #2159；或 |
|  | 3. 进入重度疲劳场景（时序上请先取消轻度疲劳后触发重度疲劳） |
|  | 配置信息：`FATIGUE_QUIT_TIME = 0.2`（轻度） |
| 重度疲劳 | 1. 非闭眼时长超过 0.4 秒（t ≥ 0.4s）；或 |
|  | 2. 用户 Dismiss Alert #2161 |
|  | 配置信息：`FATIGUE_QUIT_TIME = 0.4`（重度） |

若系统出现故障，应退出所有疲劳报警等级。

### 0.1.3 报警冷却期

- 轻度疲劳提醒冷却期：60 秒（从上一次报警解除开始计算）
  - 配置信息：`FATIGUE_COOL_TIME_1 = 60`
- 重度疲劳提醒冷却期：0 秒（无冷却期）
  - 配置信息：`FATIGUE_COOL_TIME_2 = 0`

## 0.4 头部姿态异常报警条件及除外工况

### 0.4.1 触发头部姿态异常报警条件

下方提到的除外工况无需监测头部异常。

| 类型 | 判断条件 |
|---|---|
| 头部姿态异常 | 头部姿态异常特征动作持续 3 秒以上（t ≥ 3s） |
|  | 配置信息：`HEAD_TIME = 3` |
|  | Notes：如果某一方向转头低于此计时，又经过正前方转向另一方向，则需重新计时 |

### 0.4.2 退出头部姿态异常报警条件

| 类型 | 判断条件 |
|---|---|
| 头部姿态异常 | 未出现头部姿态异常特征动作持续 0.25 秒以上（t ≥ 0.25s） |
|  | 配置信息：`HEAD_QUIT_TIME = 0.25` |

若系统出现故障，应退出头部姿态异常报警。

### 0.4.3 报警冷却期

- 头部姿态异常报警冷却期：30 秒（从上一次报警解除开始计算）
  - 配置信息：`HEAD_SIGHT_COOL_TIME = 30`

### 0.4.4 触发报警的除外工况

- 转向灯开启时：
  - 条件：`Left Turn Lamp Active != 0` 或 `Right Turn Lamp Active != 0`
  - 后 1 秒内不进行头部姿态异常监测
  - 配置信息：`TURN_LAMP_TIME = 1`

- 方向盘偏转角度大于阈值时：
  - 后 3 秒内不进行头部姿态异常监测
  - 配置信息：`STEERING_WHEEL_TIME = 3`

## 0.5 视线分心报警条件及除外工况

### 0.5.1 触发视线分心报警条件

下方提到的除外工况无需监测视线分心。

| 类型 | 判断条件 |
|---|---|
| 长时分心 | 视线分心特征动作持续 3 秒以上（t ≥ 3s） |
|  | 配置信息：`SIGHT_TIME = 3` |
|  | Notes：如果分心计时内看向安全区域或看向其他分心区域又返回，则需重新计时 |
| 累积分心 | 当驾驶员在 30 秒内每次注视某一分心区域时间不足 3 秒、每次注视安全区域时间不足 2 秒，并且累计注视分心区域时间达到 9 秒以上（t ≥ 9s） |
|  | 配置信息：`SIGHT_LONG_TIME = 9` |

**Notes：**  
长时分心 CNCAP、IVISTA、CIASI 要求均为 3 秒；累积分心为 IVISTA 要求。低灵敏度下无累积分心。

### 0.5.2 退出视线分心报警条件

| 类型 | 判断条件 |
|---|---|
| 长时分心 | 未出现视线分心特征动作持续 0.25 秒以上（t ≥ 0.25s） |
|  | 配置信息：`SIGHT_QUIT_TIME = 0.25` |
| 累积分心 | 未出现视线分心特征动作持续 2 秒以上（t ≥ 2s） |
|  | 配置信息：`SIGHT_LONG_QUIT_TIME = 2` |

若系统出现故障，应退出视线分心报警。

### 0.5.3 报警冷却期

- 视线分心报警冷却期：30 秒  
  从上一次报警解除开始计算。  
  视线长时/累积分心和头部姿态长时/累积分心共享冷却时间及冷却状态。
  - 配置信息：`HEAD_SIGHT_COOL_TIME = 30`

### 0.5.4 触发报警除外工况

- 转向灯开启时：
  - 条件：`Left Turn Lamp Active != 0` 或 `Right Turn Lamp Active != 0`
  - 后 1 秒内不进行视线分心监测
  - 配置信息：`TURN_LAMP_TIME = 1`

- 方向盘偏转角度大于阈值时：
  - 后 3 秒内不进行视线分心监测
  - 配置信息：`STEERING_WHEEL_TIME = 3`

## 0.6 报警要求

1. DMS 系统工作条件为 D 档全速域，DMS 对应总线信号应在 D 档全速域实时发给 ADAS 模块。

2. 当车辆速度 ≥ 18 km/h 时，系统针对算法输出的结果进行报警提示。

3. 仅当 DMS 算法判断达到报警阈值且在 2 秒内，当车速从 < 18 km/h 变成 ≥ 18 km/h 时，如果系统不在报警提示状态，则先抑制报警 1 秒，再根据算法输出结果进行对应报警；  
   如果达到报警阈值但超过 2 秒之后，车速从 < 18 km/h 变成 ≥ 18 km/h 时，则本次分心 / 疲劳报警周期内不再进行报警。

4. 若处于报警状态且不符合报警退出条件，车速降到 30 km/h 以下不会取消报警状态。

报警要求仅针对视觉或听觉报警提示；

## 0.7 优先级排序

应具备主动安全报警优先级排序的功能，并满足以下要求：

- 报警排序从高优先级到低优先级顺序应为：  
  驾驶员行为监控功能失效报警  > 疲劳驾驶报警   > 驾驶员分心报警（头部异常 & 视线分心）  > 驾驶员分心报警（接打手持电话报警）  > 驾驶员分心报警（抽烟报警）

- 仲裁模块：`DMS`
