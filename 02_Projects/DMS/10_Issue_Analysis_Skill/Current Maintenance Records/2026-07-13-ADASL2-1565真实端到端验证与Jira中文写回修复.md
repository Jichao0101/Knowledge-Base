## 2. 真实 case 证据

- 飞书命中 1 条未标记“已经过AI分析”的 ready 记录，负责人为贺圣艺，数据路径为 `/mnt/d/log_test`。

- 数据目录包含 1 个 A 核候选日志 `calmcar_camera_service.log`，共 308 个物理行；A 核索引满足 `total_lines = parsed_lines + unparsed_lines`，结果为 308/308/0，证据选择未截断。
- 日志出现 camera service semaphore/共享内存初始化失败，以及两组 `Cameras Not ready` → `Process frame failed`；但缺少与误报时间对齐的头姿、视线、行为状态、阈值、持续时间和最终分心告警链，不能把 camera service 异常直接确认为误报根因。
- 飞书表格保持只读，本轮未更新“已经过AI分析”字段。

## 3. Jira 写回结果与格式缺陷

- 首次真实写回成功，评论 ID 为 `8654391`。该评论正文由英文 A-core review 透传，且 Markdown `##` / `###` 被 Jira Server v2 的 Wiki Markup renderer 解释为多级有序列表，页面出现重复的 `1. 1. 1.`。
- 根因是模板语法不匹配：Jira Wiki Markup 中行首 `#` 表示有序列表层级，不是 Markdown 标题。
- Skill 已改为强制 Jira 用户可见摘要和分析条目包含中文；纯英文正文在联网前 fail-closed。
- 评论模板已改用 `h2.` / `h3.` 标题、`*` 列表和 `bq.` 引用，并禁止渲染结果出现行首 `#`。
- 中文纠正版评论 ID 为 `8654396`。现行策略只允许新增评论，不允许修改或删除既有评论，因此英文评论作为历史事实保留。
