## 0.2 Root Cause Hypotheses

- 主导根因：
  - face/hand 命中检测后仍把 `CorrectMotion` 的校正框回写为输出框，导致历史轨迹过冲后可吸附错误检测。
  - orphan/unmatched face 的 second pass 只依赖 `iou + distance + size` 总分，没有显式 distance gate，旧前排 face 轨迹可能接管远处后排 face 检测。
- 次级根因：
  - unique-driver 逻辑曾把落选 `DRIVER` 无条件降为 `FRONT_PASSENGER`，会放大错误身份传播。
- 已排除假设：
  - body small-face ratio 不是本轮接受的修复方向，已回退。

## 0.3 Accepted Implementation

- `computePersonType()` 恢复为纯 ROI 判定，body 不再使用 small-face ratio。
- unique-driver 不再硬编码把落选 `DRIVER` 降为 `FRONT_PASSENGER`，改为按非-driver 历史票回退。
- face/hand 命中检测时，`CorrectMotion` 只更新内部状态，最终输出 `box/predBox` 直接使用 detection box。
- orphan/unmatched face second pass 增加 distanceLoss gate：
  - 普通 unmatched face: `0.65`
  - true orphan face: `0.45`
- 新增最小调试日志：
  - `track det-hit ...`
  - 继续保留 `driver orphan face match ... dist=...`
