## 0.1 Task

- task_type: `bug_fix`
- goal: 修复 face/body/hand 在快速运动后恢复正常位姿时的预测-更新失配
- constraints:
  - 保持 face 更新完全使用检测框
  - 保持 hand 更新完全使用检测框
  - 降低 body 更新阶段预测主导程度
  - 不改全图检测主流程
  - 不扩展到行为识别、疲劳后处理或无关模块

## 0.2 Root Cause Hypotheses

- dominant:
  - 命中检测后输出框仍被 `CorrectMotion` 后的滤波状态主导，导致恢复阶段保留旧速度惯性
- secondary:
  - 缺少对“预测方向与检测方向明显相反”或“预测明显过冲”的预测残留抑制
- ruled_out:
  - 不是全图检测主流程问题
  - 不是 body/face/hand 生命周期或 orphan 清理逻辑主导本缺陷

## 0.3 Implementation Plan

1. 为 body/face/hand 增加统一的预测残留抑制判定，识别反向恢复、明显过冲和快速回正。
2. face 命中检测后最终输出框直接使用检测框；若命中抑制条件，则重建 CV 状态，清掉旧速度残留。
3. hand 命中检测后最终输出框直接使用检测框；若命中抑制条件，则重建 CA 状态；miss 输出逻辑保持不变。
4. body 命中检测后改为检测主导融合；若命中抑制条件，则直接使用检测框并重建 CV 状态。

## 0.4 Code Changes

- changed:
  - `/home/jichao/dms/source/utils/track.cpp`
- key changes:
  - 新增 `ShouldSuppressPredictionCarryover(...)`，用上一帧框、预测框和检测框的方向/位移关系判断是否应抑制旧速度残留
  - body 更新路径改为检测主导融合，反向/过冲时直接回检测框并重建 motion state
  - face 两条命中检测路径改为“输出框等于检测框”，不再让 `CorrectMotion` 结果覆盖输出
  - hand 两条命中检测路径改为“输出框等于检测框”，保留 miss 时沿 `predBox` 输出
