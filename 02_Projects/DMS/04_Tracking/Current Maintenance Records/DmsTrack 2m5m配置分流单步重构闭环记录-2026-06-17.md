# 1 变更摘要

本轮按 subpower 单步执行，选择 2026-06-16 收缩路线中的第一步：基于 `track_params.json` 的 `camera_type` 实现 2m/5m 第一层分流。

代码变更：

- `TrackParameters` 增加 `enableBodyTracking` 与 `enableHandTracking`，默认开启。
- `loadConfigFromJson` 先读取 `DEFAULT.camera_type`，再读取车型节点覆盖。
- `camera_type == "2m"` 时关闭 body/hand tracking；其他值保持开启。
- `DmsTrack::Update` 保持 face/head 更新与发布不变。
- body/hand disabled 时跳过 `updateBodyTracks` 与 `updateHandTracks`，并清理 `m_bodyTracks`、`m_retiredBodyTracks`、`m_handTracks`，避免旧 body/hand cache 继续污染输出。

# 2 边界

保持不变：

- `DmsTrack::Init` / `DmsTrack::Update` public API。
- 四类 legacy map ABI。
- 5m 路径现有 body/hand 行为。
- 既有 face/head driver identity 主线。

未引入：

- `Row/View/Payload/Result` 新类型。
- Body global assignment、Hand global slot assignment、Reacquire 或 independent lifecycle 扩张。
- face occlusion 业务分支。
