# 1 DmsTrack 状态收敛与输出投影隔离闭环记录

## 1.1 改动目标

本轮目标是在不改变 tracking 行为正确性的前提下，收敛 DmsTrack 的状态源与数据流：

- 消除 `curResult->m_bodyTrackResultMap` 作为 hand 阶段内部输入的 output-as-input 依赖。
- 保留 `body` 团队既有命名，但明确 body 仍是 face/head-owned evidence / search envelope，不是 identity owner。
- 引入单帧只读 `FrameBodyView`，用于把 body 输出投影传递给 hand 阶段。
- 清理本轮确认废弃的 `m_hasPreviousFrame`。

## 1.2 代码范围

- `/home/jichao/dms/include/utils/track.h`
- `/home/jichao/dms/source/utils/track.cpp`

未改动：

- `hungarian()` 实现
- `DmsTrack::Init/Update` public API
- `AtomicResult` 四类 legacy output map ABI
- assignment 行列方向
- strict `< dummyLoss` 语义

## 1.3 实现摘要

新增 private `FrameBodyView`：

```cpp
struct FrameBodyView {
    track_id ownerFaceId = kInvalidTrackId;
    TrackInfo body{};
};
```

设计约束：

- 只在单帧 `Update()` 调用栈内存在。
- 不作为 `DmsTrack` member。
- `body` 使用拷贝，hand 阶段不能通过 view 回写 `m_bodyTracks` 或 legacy output map。
- 内容由 body finalize / output boundary 生成，等价于本帧 body legacy output 的 hand 可见语义。

更新后的数据流：

```text
updateBodyTracks
  -> update m_bodyTracks
  -> prepareBodyTracksForOutput
  -> produce FrameBodyView
  -> publishBodyTracks writes curResult->m_bodyTrackResultMap from FrameBodyView

updateHandTracks
  -> consume FrameBodyView
  -> update m_handTracks
  -> publish hand maps
```

## 1.4 已清理废弃部分

- 删除 `m_hasPreviousFrame` 声明与 `Init()` 初始化；静态搜索确认没有剩余引用。
- hand 阶段不再读取 `curResult->m_bodyTrackResultMap`：
  - `collectAllowedHandOwners`
  - `buildHandSlots`
  - `cleanupRetiredOwnerHandSlots`
  - `publishAllowedHandSlots`

当前 `m_bodyTrackResultMap` 在 `track.cpp` 中只剩：

- 每帧清空
- 从 `FrameBodyView` 投影写入 legacy body output

## 1.5 行为边界

本轮保持：

- body output key 仍为 owner face id。
- hand output key 仍为 owner face id。
- hand owner 仍只来自本帧可输出且 stable 为 DRIVER 的 body evidence。
- `FrameBodyView` 顺序来自 `m_bodyTracks` map 顺序，保持既有 body output order。
- hand slot 仍按每个 owner left-before-right 构建。
- sanitize 成功仍回写内部 body/hand track；sanitize 失败仍只对本帧 matched track/slot 额外推进 miss。
- retired body anchor cleanup 仍使用本帧可输出 body evidence 与 retired body spatial anchor 判断。

## 1.8 结论

本轮关闭 output-as-input 结构问题：hand 阶段不再依赖 body legacy output map 作为内部决策输入，改为消费单帧只读 `FrameBodyView`。`curResult` 四类 map 回到 output projection 角色。

本轮不声称 tracking 运行效果已验收；后续若继续收敛 lifecycle phase boundary，应在本轮基础上继续保证 sanitize/miss、left/right slot、retired body cleanup 和 output key 行为等价。
