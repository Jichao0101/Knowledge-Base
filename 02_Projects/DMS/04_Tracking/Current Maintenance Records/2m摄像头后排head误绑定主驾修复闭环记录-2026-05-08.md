## 0.1 Task

- task_type: `bug_fix`
- defect_type: `functional_bug`
- target: 后排或非主驾 head 不得因异常宽 driver body box 被绑定到主驾 track
- scenario: 2m 摄像头下视角较扁平，前后排 head 尺度差异不明显；主驾伸手时 body box 可能异常变宽、中心漂移
- code_scope:
  - `/home/jichao/dms/source/utils/track.cpp`

## 0.2 Root Cause

- 当前 tracker 以 `body` 作为主锚点，`face/head` 在稳定 `body` 后继承 `bodyId`。
- first pass 中 face 先按当前 body ROI 过滤，已有 face track 再按 face 预测连续性打分。
- 2m 场景下 driver body box 异常变宽时，`FaceBelongsToBody` 的横向范围随 body width 扩张，后排或非主驾 face 可能进入 driver body 候选集合。
- 历史实现已有 orphan/unmatched face second pass distance gate，但 first pass 里已有 face track 缺少等价的 driver 级连续性门控；若只在 first pass 加 reject，又可能被 second pass 同帧绕回。

## 0.3 Accepted Implementation

- 新增 `PassFaceTrackContinuityGate`：
  - driver 相关绑定使用 `distanceLoss <= 0.45`
  - 非 driver 绑定使用 `distanceLoss <= 0.65`
  - 总分必须小于 face `dummyLoss`
- first pass 中已有 face track 若未通过 continuity gate：
  - 打印 `driver face reject ... score/iou/dist/size/body/face`
  - 记录到 `continuityRejectedFaceTracks`
  - 同帧 second pass 不再允许该 face track 绕回匹配
- second pass 继续保留，作为 face 启动后的自维持路径：
  - true orphan face 和 driver face 都使用严格 `0.45` distance gate
  - 非 driver 非 orphan face 仍使用 `0.65` gate
  - 日志由 `driver orphan face match` 改为 `driver second-pass face match ... orphan=%d`
