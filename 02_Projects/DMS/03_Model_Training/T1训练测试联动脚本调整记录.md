# 1 变更摘要

- `t1_train_grid.sh` 现在会在每个 run 的训练完成后，立即检查 `best.pth` 是否生成。
- 若 checkpoint 存在，则直接对该 checkpoint 执行 `test-only`。
- 测试结果统一写入 `${run_dir}/test_fp32/`，与该次训练输出绑定。

# 2 设计取舍

- 没有把 `test_summary.json` 直接写到 `run_dir` 根目录。
- 原因是 `train_rois.py` 在 `test-only` 模式下仍会重写 `hparams.json`，若直接复用 `run_dir`，会污染训练期参数记录。
- 因此保留 `run_dir/test_fp32/` 作为同一次训练输出下的测试子目录，既满足“放在训练输出里”，也避免覆盖训练元数据。

# 3 验证

- 已在容器内执行 `bash -n /workspace/scripts/t1_train_grid.sh`
- 已检查脚本 diff，确认训练后紧接测试的调用顺序生效
