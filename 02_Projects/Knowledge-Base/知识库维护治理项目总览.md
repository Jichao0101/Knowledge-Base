# 1 知识库维护治理项目总览

## 1.1 项目目标

本项目不以“建设更强的知识库系统”为目标，而以以下结果为目标：

> 防止已有修复、约束和当前事实源在后续写入中被静默覆盖，并保证高风险写入能够追溯到相关 Markdown 原文和验证证据。

## 1.2 当前事实源

| 内容 | 当前入口 | 状态 |
|---|---|---|
| 实施方案 | [[02_Projects/Knowledge-Base/知识库防静默覆盖治理实施方案]] | active plan，尚未实现 |
| 当前结构状态 | [[02_Projects/Knowledge-Base/知识库结构审计_current]] | active audit |

## 1.3 默认读取顺序

1. 本项目总览。
2. [[02_Projects/Knowledge-Base/知识库防静默覆盖治理实施方案]]。
3. 需要核对当前结构状态时读取 [[02_Projects/Knowledge-Base/知识库结构审计_current]]。
4. 需要核对外部参考时读取来源证据卡及其原始链接。

## 1.4 当前阶段

- 当前处于方案固化阶段，尚未修改 `knowledge-base-structure-builder` skill 或新增 lint/index 工具。
- 尚未运行实现测试或中文检索 tokenizer 基准。
- 暂不建立五份 current 文档组：目前缺少 implementation 与 validation 事实，使用项目总览加 active 方案即可恢复当前状态。
- 后续若该项目进入长期实现和反复维护，再按 current lifecycle 评估是否创建 design/spec/implementation/validation current 文档组。

## 1.5 非目标

- 不建设通用知识图谱平台。
- 不以 SQLite、搜索索引或报告替代 Markdown 事实源。
- 不自动推断知识真伪或为每条 claim 赋予浮点概率。
- 不自动提升正式知识、解决 supersession 冲突或删除历史记录。
- 不在基准评测前直接引入向量检索。

## 1.6 当前未解决项

- Schema v2、preflight report 和 Traceability Index 的机器可读格式尚未实现。
- 历史文档缺省解释策略尚未落入工具。
- `知识库结构审计_current.md` 仍承载较多历史维护流水，等待阶段 4 去历史化。
- 中文全文检索技术选型必须等待阶段 6 基准结果。
