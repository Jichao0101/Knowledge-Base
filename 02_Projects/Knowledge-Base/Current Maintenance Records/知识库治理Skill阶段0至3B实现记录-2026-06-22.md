# 2 当前行为契约

## 2.1 事实源与派生物

- Markdown 仍是唯一事实源。
- `.kb_cache/metadata/` 和 `.kb_cache/trace-index/` 仅保存可重建缓存。
- `reports/kb/lint/` 和 `reports/kb/preflight/` 仅保存运行报告。
- 知识库 `.gitignore` 已忽略 `.kb_cache/` 和 `reports/kb/`，避免派生物污染事实提交。

## 2.2 Metadata

- 读取最小 declared frontmatter。
- legacy `source/sources` 只映射为 effective `evidence_refs`，不修改原文。
- 输出 `declared/effective/value_origin`。
- 日期等 YAML 类型在派生 JSON 中规范化为字符串。

## 2.3 Lint

- 只读检查入口、wikilink、孤儿页、Schema v2 enum、正式知识元数据、supersession 和 recoverability 声明。
- legacy status 不因未迁移到 Schema v2 而被批量判错。
- Obsidian 目录链接和代码块内的双中括号不会被当作普通断链处理。

## 2.4 Traceability 与 Gate

- strong/medium/weak 为派生信号，maintenance records 保持弱信号。
- strong 或 guarded/critical 命中会读取 Markdown 原文并记录 section、行号和 hash。
- gate 全量评估规则，并按 `blocked > manual_review > allow` 合并。
- append-only 改写、授权不足、原文不可读、缺少显式 supersession、强信号未读和冲突链均 fail-closed。
- `free_update` 不豁免 preflight。
- 显式 trace index 带全库 Markdown 内容指纹；索引过期时直接阻断。
- 新建嵌套目录中的记录时，检查最近已存在且已授权的父目录。
