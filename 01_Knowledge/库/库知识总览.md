# 库知识总览

本主题收录常用工程库的使用笔记和工程实践，当前主要覆盖 OpenCV 与 PyTorch。

## 1 主入口

| 分组 | 入口 | 内容简介 |
|---|---|---|
| OpenCV | [[01_Knowledge/库/OpenCV]] | OpenCV 数据结构、图像处理、几何、PnP、工程实践和 CMake 集成 |
| PyTorch | [[01_Knowledge/库/pytorch]] | Tensor、Dataset/DataLoader、训练、推理、保存加载和调试技巧 |

## 2 读取规则

1. 图像处理、几何和 C++ 视觉工程问题优先读 OpenCV。
2. 深度学习训练、推理和张量操作问题优先读 PyTorch。
3. 具体 API 版本和边界应结合项目代码或官方文档核对。
