# 模型软件栈与框架分工来源记录

核对日期为2026-11-15。用户要求将已讨论的软件层级独立整理为P02A-00前置学习文档。以下为官方资料的归纳，采用项目教学材料的放置方式。

| 来源 | 支持内容与适用边界 |
|---|---|
| [ms-swift命令参数](https://swift.readthedocs.io/en/latest/Instruction/Command-line-parameters.html) | infer_backend可选择Transformers、vLLM、SGLang、LMDeploy。具体支持范围依版本及模型。 |
| [ms-swift推理部署](https://swift.readthedocs.io/en/v3.10/Instruction/Inference-and-deployment.html) | 工作流整合不同推理引擎，模板与后端配置需要一起核对。 |
| [vLLM架构](https://docs.vllm.ai/en/latest/design/arch_overview/) | 推理引擎包含调度、执行及模型运行组件，模型和算子路径应按实际配置识别。 |
| [Transformers模型后端](https://huggingface.co/docs/transformers/main/en/transformers_as_backend) | 支持的推理服务可以复用Transformers模型实现，不能假定所有vLLM配置都调用同一种forward。 |
| [Transformers 5.2.0 attention接口](https://huggingface.co/docs/transformers/v5.2.0/en/attention_interface) | attention实现可按vision_config和text_config分别选择。 |
| [PyTorch SDPA](https://docs.pytorch.org/docs/main/generated/torch.nn.functional.scaled_dot_product_attention.html) | SDPA为接口，按条件选择底层实现，可使用FlashAttention。具体实现集合依版本变化。 |
| [FlashAttention](https://github.com/Dao-AILab/flash-attention) | 独立优化实现与Python接口、硬件/dtype限制及变长序列支持。 |
| [Qwen3.5 v5.2.0源码](https://github.com/huggingface/transformers/blob/v5.2.0/src/transformers/models/qwen3_5/modeling_qwen3_5.py#L915-L956) | vision的FlashAttention分支传递cu_seqlens，其余分支逐序列调用；该案例限定版本。 |

层级图按教学目的综合上述职责，不表示所有项目必须按同一条链嵌套。内容经官方资料对照后写入[[02_Projects/AI-Career-Transition/10_学习文档/P02A-00_模型软件栈与框架分工_学习文档]]。P02A-01已有硬件机制、算子执行和profiling章节，由原文继续承载这些内容。本轮仅新增学习材料及导航，不构成框架选型或性能验收。

## 计算库与实现工具补充（2026-11-15）

本次补充用于解释PyTorch以下的软件职责，只核对接口、实现与开发工具的关系，不涉及kernel内部优化，也未执行后端性能验证。

| 来源 | 支持内容与适用边界 |
|---|---|
| [cuBLAS介绍](https://docs.nvidia.com/cuda/cublas/index.html) | GPU线性代数库及cuBLASLt矩阵乘接口；不据此推定任意PyTorch运算必经cuBLAS。 |
| [PyTorch计算后端](https://docs.pytorch.org/docs/stable/backends.html) | BLAS库选择和cuDNN SDPA控制；具体候选和支持条件随版本变化。 |
| [cuDNN attention](https://docs.nvidia.com/deeplearning/cudnn/latest/operations/Attention.html) | cuDNN提供attention计算，职责不局限于卷积。 |
| [CUTLASS概览](https://docs.nvidia.com/cutlass/latest/overview.html) | 构建高性能GPU计算的组件与抽象，包含CUDA C++模板和Python DSL。 |
| [Triton介绍](https://triton-lang.org/) | Triton是并行编程语言与编译器。 |
| [PyTorch 2.x](https://pytorch.org/get-started/pytorch-2-x/) | TorchInductor可生成Triton GPU代码；用于说明代码生成关系，不引用性能倍数。 |
| [flash-attn v2.8.3 kernel_traits.h](https://github.com/Dao-AILab/flash-attention/blob/v2.8.3/csrc/flash_attn/src/kernel_traits.h) | 该版本源码引入CUTLASS与CuTe头文件，支持实现使用这些组件的表述。 |
| [Triton Fused Attention](https://triton-lang.org/main/getting-started/tutorials/06-fused-attention.html) | 官方教程明确展示FlashAttention v2算法的Triton实现，说明同一算法可有不同实现工具。 |

补充内容写入P02A-00第1.3.1～1.3.2节，保留原有章节编号、视觉配置案例和P02A-01的硬件教学职责。
