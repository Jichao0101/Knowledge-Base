# 1 Visual Genome：怎样把局部描述落到对象上

看图像 1 的三条区域标注。三条都配有矩形，但标注员借助矩形表达的意思不同。坐标以下均为左上角 x、y 和宽、高，原图大小为 800 × 600。记录来自发布的 `region_descriptions.json` 和 `relationships.json`，可从官方下载页按图像和记录 ID 复查。[发布入口](https://visualgenome.org/api/v0/api_home)

| 区域 ID | 区域及短句的含义 | 能提取的监督 |
|---|---|---|
| 1382 | (421,57,82,139)，时钟呈绿色 | 颜色属于时钟。若任务问颜色，只需要对象和属性。 |
| 1432 | (122,14,84,178)，标牌在建筑立面上 | 要评价相对关系，需知道哪个物体是标牌、哪个是承载它的建筑。 |
| 1385 | (617,377,36,36)，车灯处于熄灭状态 | 这句话描述灯的状态。存在车灯与确认灯已熄灭是两个判断。 |

**沿一条关系检查证据。** 同图的关系 15930 以标牌 1058507 为主语、建筑 1058508 为宾语，谓词为 `ON`。标牌对象框 (118,13,88,182) 与区域 1432 接近，但两者几何范围并不完全相同。区域矩形标出描述针对的局部，关系边的两个对象 ID 则告诉读者怎样找到端点。本次按同图、描述、坐标核对，两份记录未提供该区域到该关系的显式外键。图中另一条关系 15929 只记录车拥有车灯；从这条边本身推不出灯已熄灭。[字段说明](https://visualgenome.org/api/v0/api_readme)

**怎样判错。** 若从 1432 派生“什么东西在建筑立面上”，可以把回答映射到标牌对象。若同时评关系方向，则预测“建筑位于标牌上”即使找对两个框，主宾顺序仍错。这是针对该派生题的人工评分示例。原数据支持区域描述、关系识别等不同任务，各自需要定义指标。读底层标注时应保留区域、对象和关系三种身份，以便事后区分错在定位、属性还是关联。[标注构造原论文](https://link.springer.com/article/10.1007/s11263-016-0981-7)
