# VLM 数据集的标注怎样产生

读一条图文样本，可以从最终答案往回追踪：谁观察了图像，谁写了答案，中间经过哪些转换？下表据作者论文、项目说明和数据格式整理。它用于选择精读材料。原始样本复核和座舱试标属于后续项目实践。

| 数据集 | 公开资料说明的构造方法 | 精读时应核对什么 |
|---|---|---|
| Visual Genome | 标注包含局部区域描述、对象、属性和对象间关系。论文展示了从区域描述提取对象及关系的例子。[原论文](https://link.springer.com/article/10.1007/s11263-016-0981-7) | 找一条关系，核对关系两端的对象、对应区域和原描述。 |
| VQA v2 | 为图像问题保留多个人工答案，并提供同问异答的互补图像对。官方评分包含答案归一化和多人回答的一致程度。[数据格式](https://visualqa.org/download.html)、[评测方法](https://visualqa.org/evaluation.html) | 对照一组原始回答，区分措辞差异和事实分歧，再看换图后哪条视觉证据改变了答案。 |
| GQA | 以整理后的 Visual Genome 场景图生成组合问题，问题附带表达其语义的函数程序。[官方说明](https://cs.stanford.edu/people/dorarad/gqa/about.html) | 沿程序找到回答所依赖的对象、属性或关系，检查底层关系标错会影响哪些题。 |
| LLaVA-Instruct-158K | 初代方案把图像描述和对象框作为文本输入交给语言教师，生成对话、详细描述和复杂推理三类数据，再与图像配对。[原论文](https://arxiv.org/abs/2304.08485)、[作者对数据构造的说明](https://openaccess.thecvf.com/content/CVPR2024/papers/Liu_Improved_Baselines_with_Visual_Instruction_Tuning_CVPR_2024_paper.pdf) | 对照教师收到的文字、生成答案和原图，分别标出输入已支持、需看图核实及仍属推测的内容。 |
| Drive&Act | 座舱内驾驶员行为识别采用多个粒度的活动标注。[项目与论文](https://www.driveandact.com/) | 选一段视频观察不同粒度标签的时间范围，尝试解释其中哪些判断必须依赖连续画面。 |
| DriveLM-nuScenes | 按场景和关键帧组织数据。关键对象关联相机、图像位置、框和描述，帧级问答覆盖感知、预测和规划。[数据格式](https://github.com/OpenDriveLab/DriveLM/blob/main/docs/data_prep_nus.md)、[原论文](https://arxiv.org/abs/2312.14150) | 从一条问题回到关键帧和对象，区分画面可核实的事实、对未来的预测和行为判断。 |

## 交互补充：SIMMC 2.1 怎样标记指代歧义

SIMMC 2.1 在用户轮次的 transcript_annotated 中用 disambiguation_label 标识指代是否有歧义，用 disambiguation_candidates 保存该轮合理的对象 ID。官方示例中，用户询问一件衬衫的价格，现场有多件符合描述的衬衫；候选集合列出这些实例，object 在歧义轮次为空。该机制可供座舱任务设计“尚未确定对象”的记录方式。车道次序、何时追问及具体问句由应用方另行制定。[作者数据与字段说明](https://github.com/facebookresearch/simmc2/blob/main/data/README.md)

## 按任务扩展的官方资料

以下条目按官方任务说明整理，用于指南的覆盖范围。此前六份样本精读另有原图和记录 ID；本组新增资料以任务格式核对为主。

| 任务 | 原始资料与阅读重点 |
|---|---|
| 实例、描述、指代与检索 | [COCO](https://cocodataset.org/#download) 提供检测、分割与描述入口；[RefCOCO 系列](https://github.com/lichengunc/refer) 将表达关联到实例；[Flickr30K](https://shannon.cs.illinois.edu/DenotationGraph/) 提供图像及多条描述。 |
| 组合推理 | [CLEVR](https://cs.stanford.edu/people/jcjohns/clevr/) 提供合成场景、对象属性和函数程序，用于分析计数、比较等能力。 |
| OCR、文档与图表 | [TextOCR](https://textvqa.org/textocr/dataset/) 提供场景文字标注；[TextVQA](https://textvqa.org/download/) 区分问题答案与辅助 OCR 结果；[DocVQA](https://www.docvqa.org/datasets/docvqa) 的原始单文档任务抽取页面文本；[ChartQA](https://github.com/vis-nlp/ChartQA) 包含图表问答与推理。 |
| 时序与对话 | [ActivityNet Captions](https://cs.stanford.edu/people/ranjaykrishna/densevid/) 为事件描述配起止时间；[Visual Dialog](https://visualdialog.org/) 提供图像对话上下文；[VizWiz VQA](https://vizwiz.org/tasks-and-datasets/vqa/) 涉及不可回答的真实视觉提问。 |
| 行动监督 | [BFCL](https://gorilla.cs.berkeley.edu/blogs/13_bfcl_v3_multi_turn.html) 提供多轮工具调用与执行评测思路，属函数调用参照。 |
