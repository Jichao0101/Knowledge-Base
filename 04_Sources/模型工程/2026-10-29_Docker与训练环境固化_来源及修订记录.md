# Docker 与训练环境固化：来源及修订记录

本记录先保留外部依据，再支持现有知识条目的局部结论修订。用户于 2026-10-29 授权执行两篇文档优化，并要求保留地平线示例、暂不加入其他镜像归档案例。此次不新增正式知识条目、不提高原条目状态或证据等级。

## 官方依据

以下为 2026-10-29 阅读官方资料后的概括，命令示例仍需按实际环境验证。

| 编号 | 来源 | 支持的判断 |
|---|---|---|
| D1 | [Dockerfile reference](https://docs.docker.com/reference/dockerfile/) | Dockerfile 描述构建步骤；可以复制依赖文件并通过 RUN 安装依赖。WORKDIR 指定工作目录，CMD 与继承的 ENTRYPOINT 共同决定默认启动行为。 |
| D2 | [Building best practices](https://docs.docker.com/build/building/best-practices/) | 标签可能变化；固定基础镜像摘要有助于锁定输入。多阶段构建可只把所需产物放入最终镜像；运行镜像不必包含完整构建 SDK。 |
| D3 | [docker image save](https://docs.docker.com/reference/cli/docker/image/save/) / [docker image load](https://docs.docker.com/reference/cli/docker/image/load/) | save 保存镜像归档，load 恢复镜像及标签；归档不等于原始 Dockerfile 或宿主机数据备份。 |
| D4 | [docker container export](https://docs.docker.com/reference/cli/docker/container/export/) / [docker image import](https://docs.docker.com/reference/cli/docker/image/import/) | export 导出容器文件系统且不包含关联卷内容，import 从文件系统归档创建镜像；两者不等同于镜像的 save/load。 |
| C1 | [Managing environments](https://docs.conda.io/projects/conda/en/stable/user-guide/tasks/manage-environments.html) | YAML 用于描述环境；explicit specification 记录具体 Conda 包，通常限定同一平台。依赖恢复不能单独保证训练结果复现；项目中的 pip 依赖也需要记录和核对。 |
| C2 | [conda run](https://docs.conda.io/projects/conda/en/stable/commands/run.html) | conda run 可以指定环境运行命令，可用于容器启动，不必依赖交互式 shell 的初始化文件。 |
| N1 | [NVIDIA Container Toolkit installation](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html) | GPU 容器需要宿主机 NVIDIA 驱动与容器运行时配置，不能仅靠 Dockerfile 保证 GPU 可用。 |

- [NVIDIA PyTorch 24.10 发布说明](https://docs.nvidia.com/deeplearning/frameworks/pytorch-release-notes/rel-24-10.html)：支持训练篇的 Ubuntu、Python、PyTorch、CUDA、cuDNN、NCCL、TensorBoard 版本与 `/opt/pytorch` 路径。该版本使用默认 Python 环境，不预设 Conda；从 24.10 起不再测试 Volta。仅核对文档，不代表本机已拉取或验证。
- [NVIDIA NuRec 文档中的镜像拉取命令](https://docs.nvidia.com/nurec/archives/26.03/fixer/model.html)：确认 `nvcr.io/nvidia/pytorch:24.10-py3` 是官方使用的真实镜像引用；不将该页面的推理任务当作训练案例。

核对日期为 2026-10-29。选择 24.10 是为了固定说明对象，不代表推荐使用旧版本；实际选择还需检查目标硬件和版本维护情况。官方框架源码不等于用户的模型训练代码，官方组件清单也不等于完整项目交付清单。此前 Conda 安装片段保留为可选路径，不套用到此默认 Python 环境。
