## 官方依据

2026-11-05 核对下列资料。它们支持构建机制和命令设计；项目版本组合仍需实机验收。

| 来源 | 支持的判断 |
|---|---|
| [Docker 构建缓存失效](https://docs.docker.com/build/cache/invalidation/) | 未变化的层可复用；安装层变化会使后续层重新构建，缓存命中本身不重新验证包源内容。 |
| [pip 可重复安装](https://pip.pypa.io/en/stable/topics/repeatable-installs/) | 固定直接和间接依赖、校验包内容及保存安装包，可以逐步加强安装可重复性；平台适用范围仍需记录。 |
| [Docker push](https://docs.docker.com/reference/cli/docker/image/push/) | 经标签标识的镜像可推送至仓库；目标机器拉取后仍需运行验证。 |
| [NVIDIA 性能计数器权限](https://developer.nvidia.com/ERR_NVGPUCTRPERM) | 工具安装与硬件计数器访问权限分别检查；Linux 容器权限取决于宿主机策略和运行权限。 |
| [Transformers 5.2.0 Qwen3.5 源码](https://github.com/huggingface/transformers/blob/v5.2.0/src/transformers/models/qwen3_5/modeling_qwen3_5.py) | 包含 Qwen3_5ForConditionalGeneration 和可选加速实现选择；可作为候选实现依据。 |
| [Qwen3.5-0.8B 模型卡](https://huggingface.co/Qwen/Qwen3.5-0.8B) | 提供图文生成模型权重与使用说明；用于设计小模型冒烟测试。 |
| [Transformers 5.2.0](https://pypi.org/project/transformers/5.2.0/)、[Accelerate 1.12.0](https://pypi.org/project/accelerate/1.12.0/)、[Pillow 12.1.1](https://pypi.org/project/pillow/12.1.1/) | 对应发行版可供选型；发行存在不等于组合运行验证通过。 |
