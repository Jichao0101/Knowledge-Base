# 哨兵 AGENT API 选型与预算来源记录

本记录支持 [[02_Projects/哨兵AGENT/哨兵AGENT方案#1.5 API 选型与成本]] 的采购前评估。查询日期为 2026-10-23；仅核对公开资料，未调用付费 API，未复跑 benchmark。

## 1. 阿里云价格与计费规则

来源：[模型调用价格](https://help.aliyun.com/zh/model-studio/model-pricing)。

北京地域目录价，单位为人民币元/百万 tokens：

| 模型 | 输入 | 输出 | 条件 |
|---|---:|---:|---|
| qwen3.8-max | 12 | 36 | 输入不超过 1M |
| qwen3-vl-plus | 1 | 10 | 输入不超过 32K |
| qwen3-vl-plus | 1.5 | 15 | 输入大于 32K、不超过 128K |
| qwen3-vl-plus | 3 | 30 | 输入大于 128K、不超过 256K |
| qwen3-vl-embedding | 图像/视频 1.8 | — | 文本单价另为 0.7 |

输出价格覆盖计费思考过程与回答。预算不扣除免费额度、缓存和 Batch 优惠。价格及可用地域在申请或接入时可能变化。

## 2. Qwen 图像输入与 Embedding

来源：[图像与视频理解](https://help.aliyun.com/zh/model-studio/vision/)、[多模态 Embedding API](https://www.alibabacloud.com/help/en/model-studio/multimodal-embedding-api-reference)。

视觉接口支持单图与多图。Qwen3.8、Qwen3-VL 的图像 token 近似为处理后图像面积÷1,024＋2；缩放尺寸和像素参数影响用量。官方说明以实际 API 用量为准。

Embedding 接口用于图像等模态的向量提取。项目计划使用独立图像向量；判别模型的 token 规则不直接视为 Embedding 的计费规则。

## 3. Qwen 公开性能

来源：[Qwen3.8-Max 初始发布报告](https://qwen.ai/blog?id=qwen3.8)，发布于 2026-08-03。

报告列出 MMMU-Pro 82.3、BabyVision 无工具 82.0。来源为厂商评测披露；本文仅引用无工具口径。分数用于判断视觉能力档位，不直接描述九类危险行为准确率，也不自动覆盖后续更新的 API 版本。本次未取得 Qwen3-VL-Plus 精确 API 版本与该报告可对齐的分数。

## 4. DeepSeek 能力与价格

来源：[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

查询时 `deepseek-flash` 对应 DeepSeek-V4.1-Flash-1017，支持图像理解。人民币未命中缓存输入/输出价格：高峰为 2/8 元每百万 tokens，空闲为 1/4 元。预算比较采用高峰价。本次未取得对应版本可对齐的视觉 benchmark，因此保留性能证据缺口，而不将缺失解释为性能较差。

## 5. Kimi 能力、性能与价格

来源：[官方 Kimi-K3 仓库](https://github.com/MoonshotAI/Kimi-K3)、[官方发布介绍](https://www.kimi.com/en/blog/kimi-k3)、[当前计费说明](https://platform.kimi.com/docs/pricing/chat)。

官方仓库列出：MMMU-Pro 无工具 81.6、PerceptionBench 58.5、Video-MME 含字幕 90.0。报告使用最大思考强度，不同任务设置以仓库脚注为准。上述指标与 Qwen 报告来自不同评测环境，不能据小幅分差推导确定优劣。

官方发布介绍给出的美元价格为未命中缓存输入 3 美元、输出 15 美元每百万 tokens。当前计费说明另有 K3 缓存写入计费规则；本次抓取未获得完整人民币价表，因此只将美元发布价列为参考，不用于人民币申请总额。

## 6. 项目推导与使用边界

项目选择 Qwen 的依据是视觉证据、判别与向量接口覆盖及可核算的人民币预算，属于工程选型判断。它不是“三家性能已完成同台验证”的结论。

库规模、每月报警量、1,024 tokens/图、2,048 输出 tokens、25% 在线复判率及 30% 预留均是项目预算假设，不是外部来源事实。1,100 元首期额度由方案中的公式计算，未执行充值或采购。真实识别效果、延迟、Embedding 平均用量和计费输出长度待获批后验证。
