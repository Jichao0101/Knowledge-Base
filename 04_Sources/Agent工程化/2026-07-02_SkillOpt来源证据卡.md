# 1 SkillOpt 来源证据卡

## 1.1 来源

- 标题：SkillOpt: Executive Strategy for Self-Evolving Agent Skills
- 来源：arXiv
- 链接：https://arxiv.org/abs/2605.23904
- 日期：2026-05-22
- 作者：Yifan Yang, Ziyang Gong, Weiquan Huang, Qihao Yang, Ziwei Zhou, Zisu Huang, Yan Li, Xuemei Gao, Qi Dai, Bei Liu, Kai Qiu, Yuqing Yang, Dongdong Chen, Xue Yang, Chong Luo
- 机构信息：论文页面显示作者关联包括 Microsoft。

## 1.2 核心事实摘记

SkillOpt 的核心对象不是模型权重，而是 agent 使用的外部 skill 文档。执行模型保持冻结，优化器模型根据 scored rollouts 生成受限文本编辑，候选 skill 只有在 held-out validation 上严格超过当前 best skill 时才被接受。

论文将 SkillOpt 描述为 text-space optimizer，关键机制包括：

- Rollout：目标 agent 使用当前 skill 执行任务，收集消息、工具调用、反馈和分数。
- Reflect：优化器模型分析成功与失败轨迹，提取可复用操作规则。
- Edit：对 skill 文档执行 add、delete、replace 等受限编辑。
- Gate：候选 skill 必须在 held-out validation 上提升，才进入 best skill。
- Export：导出可部署的 skill artifact，推理时目标模型读取该 skill，不增加额外推理阶段模型调用。

论文强调的稳定性控制包括：

- textual learning-rate budget：限制每轮文本编辑幅度。
- rejected-edit buffer：保存被验证门拒绝的编辑，减少重复有害更新。
- slow/meta update：维护优化器侧长期记忆，但不把优化器记忆带入部署推理链路。

## 1.3 实验结论摘记

论文报告 SkillOpt 覆盖 6 个 benchmark、7 个目标模型和 3 种执行 harness，包括 direct chat、Codex 和 Claude Code。摘要称在 52 个 model × benchmark × harness 单元上，SkillOpt 均为 best 或 tied-best，并优于 human、one-shot LLM、Trace2Skill、TextGrad、GEPA、EvoSkill 等 per-cell baseline。

论文还报告在 GPT-5.5 上，相对无 skill 的平均准确率提升包括：

- direct chat：+23.5 points
- Codex agentic loop：+24.8 points
- Claude Code：+19.1 points

论文结论还包括迁移性：优化后的 skill artifact 可以跨模型规模、跨 Codex / Claude Code 执行环境，并迁移到相近数学 benchmark，而不需要重新优化。

## 1.4 可迁移边界

可迁移到本地 Agent Workflow 的部分：

- 将 skill 文档视为可版本化、可验证、可回滚的外部策略参数。
- 用 rollout + 评分 + bounded edit + validation gate 替代无门控自我反思。
- 将 skill 发布视为类似 CI/CD 的离线优化与部署流程。
- 用 rejected-edit buffer 保留负反馈，避免重复采纳有害规则。

不可直接外推的部分：

- 论文 benchmark 提升不等同于本地 agent skill 的性能提升。
- 若没有可靠评分器、验证集和任务 harness，SkillOpt 机制会优化错误目标。
- 大规模 skill library 下仍需要 scope、冲突、优先级、版本和回滚治理。
